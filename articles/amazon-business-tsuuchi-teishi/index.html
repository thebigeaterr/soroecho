Amazonビジネスの通知を止める方法｜メール・SMS・郵送を減らす設定手順

公開日: 2026年10月21日・読了目安: 約5分

Amazonビジネスの通知は、アカウントサービスの「Eメールとメッセージ」にある「情報配信サービスの設定」で減らせます。情報配信Eメールは「すべて受信しない」にでき、郵送の案内も止められます。

ただし、注文に関する重要なメールは配信されることがあります。通知をゼロにするのではなく、「不要な宣伝を止め、必要な連絡は残す」考え方で設定するのが現実的です。

この記事は、Amazonビジネスに登録済みの方向けです。登録した覚えがないのにメールが届く場合は、こちらの記事をご覧ください。

まず確認したい：通知の種類と止められる範囲

Amazonビジネスから届く連絡は、大きく分けて次の種類があります。どれを減らしたいかで、操作する場所が変わります。

公式ヘルプによると、アカウントの更新やアクションは、通知ベル（画面上の鈴のマーク）またはEメールで知らされます。また、アカウントや注文に関するテキストメッセージ（SMS）やEメールの通知も設定できます。

種類 内容 止められるか
情報配信Eメール 新商品・セール・おすすめなどの案内 「すべて受信しない」に設定できる
ダイレクトメール 会員登録・新商品・セール・おすすめの案内 受信するかどうかを選べる
SMS 携帯電話への通知 SMSの設定で管理する
郵送 紙の情報配信 「受け取らない」に設定できる
注文に関する重要なメール 注文内容に関わる連絡 配信されることがある

「うざい」と感じる通知の多くは、上の表の上から3行目までに当たることが多いでしょう。まず宣伝系を止め、それでも気になる連絡が残るかを見る順番がおすすめです。

あなたの場合の目安は次のとおりです。

  • 宣伝メールが多すぎる：情報配信Eメールの設定へ
  • 携帯に通知が来るのが負担：SMSの設定へ
  • 封書やはがきが届く：郵送の設定へ
  • 注文関連の連絡も多い：後述の「止められないメール」を確認

手順1：設定画面を開く

すべての設定は、アカウントサービスから入ります。次の手順で開いてください。

  1. Amazonビジネスにログインする
  2. 「アカウントサービス」を開く
  3. 「Eメールとメッセージ」を選ぶ
  4. 「情報配信サービスの設定」を開く

この画面で、Eメール、SMS、ダイレクトメール、郵送といった項目を確認できます。

[要実演スクショ: アカウントサービスの「Eメールとメッセージ」画面]

[要実演スクショ: 「情報配信サービスの設定」画面]

画面の表示は、時期や利用環境で変わる場合があります。項目名が少し違うときは、公式ヘルプの案内と見比べながら進めてください。

手順2：情報配信Eメールを止める

宣伝やお知らせのメールを一括で止めたい場合は、次の操作をします。

  1. 「情報配信サービスの設定」を開く
  2. 「情報配信Eメール」の項目を選ぶ
  3. 「すべての情報配信Eメールを受信しない」を選ぶ
  4. 「保存」を押す

保存を忘れると設定が反映されないため、最後に必ず保存ボタンを押してください。

[要実演スクショ: 「すべての情報配信Eメールを受信しない」を選択した画面]

一部だけ残したい場合

すべて止めるのではなく、必要なものだけ受け取る選択もできます。公式ヘルプでは、次の調整ができるとされています。

  • どの部署からの情報配信Eメールを受け取るかを選ぶ
  • Eメールの形式を選ぶ
  • ダイレクトメールの設定で、会員登録・新商品・セール・おすすめの受信を、項目ごとに受け取る／受け取らないで選ぶ

たとえば、セールの案内だけ残して、おすすめは止める、といった使い分けが考えられます。

プログラムのメールについて

特定のプログラムに関するメールは、「Eメールご登録」で管理します。情報配信Eメールを止めても、プログラム側のメールは別に設定が必要な場合があります。止めたはずのメールが届くときは、この画面も確認してください。

手順3：SMS（携帯への通知）を設定する

SMSは、携帯電話の番号を追加することで受け取れる仕組みです。受け取りたくない場合は、番号を追加しないままにしておくのが基本です。

すでに設定している場合、または新しく設定する場合の流れは次のとおりです。

  1. 「情報配信サービスの設定」を開く
  2. SMSの設定を選ぶ
  3. 携帯番号を追加する
  4. ワンタイムパスワード（確認用の一回限りの数字）で確認する

番号の追加時には、携帯に届くワンタイムパスワードで本人確認を行います。

[要実演スクショ: SMSの設定画面]

SMSを止めたい場合の具体的な画面操作は、公式ヘルプの記載の範囲では細かく確認できません。設定画面でSMSの項目を開き、画面の案内に沿って確認してください。

手順4：郵送の案内を止める

紙のダイレクトメールが届く場合は、郵送の設定を変えます。メールの設定とは別になっているため、メールを止めても郵送は止まらないことがあります。

  1. 「情報配信サービスの設定」を開く
  2. 郵送の項目を選ぶ
  3. 「郵送での情報配信は受け取らない。」を選ぶ
  4. 「保存」を押す

[要実演スクショ: 郵送の設定画面]

自宅兼事務所で開業している個人事業主の方は、この設定が特に関係します。自宅住所に宣伝の郵便物が届くのを減らしたい場合は、メールと郵送の両方を確認してください。

止められないメールとの付き合い方

公式ヘルプには、注文に関する重要なメールは配信されることがあると書かれています。情報配信をすべて止めても、注文に関する連絡は届く場合があるということです。

これは、注文の確認や変更など、取引に必要な連絡を受け取れなくならないための仕組みと考えられます。通知を完全に消すより、次の方法で整理するのが現実的です。

  • 仕事用のメールアドレスと私用のアドレスを分ける
  • 注文関連のメールだけを、メールソフトで専用フォルダに振り分ける
  • 通知ベルの表示は、まとめて確認する時間を決める

「あなたの場合」の考え方

  • 個人事業主（ひとりで利用）：宣伝系をすべて止め、注文関連だけ残す形が管理しやすい
  • 従業員がいて複数人で使う：担当者ごとに受け取りたい連絡が違うため、部署ごとの配信の選択を見直す
  • 発送件数が多いネットショップ運営者：注文関連の連絡を見落とさないよう、止めすぎに注意する

設定後に確認すること

設定を変えたら、次の点を確認しておくと安心です。

  1. 設定画面をもう一度開き、変更が保存されているか見る
  2. しばらく届くメールを観察し、止まらないものの種類を確認する
  3. 届き続けるものが宣伝か、注文関連かを見分ける
  4. 宣伝なのに届く場合は、プログラムのメール（「Eメールご登録」）も確認する

アカウントの種類によって使える機能が違うため、個人用との違いが気になる方はAmazonビジネスと個人アカウントの違いも参考にしてください。見積書の取得など実務の流れは見積書の発行手順で解説しています。

よくある質問

QAmazonビジネスの通知をすべて止めることはできますか？

A情報配信Eメールは「すべての情報配信Eメールを受信しない」を選んで保存すると止められます。ただし、注文に関する重要なメールは配信されることがあると公式ヘルプに記載されています。

QSMS（携帯への通知）はどこで設定しますか？

Aアカウントサービスの「Eメールとメッセージ」から「情報配信サービスの設定」を開き、SMSの設定で行います。携帯番号を追加する際は、ワンタイムパスワードで確認します。

Q郵送のダイレクトメールも止められますか？

A情報配信の設定画面で「郵送での情報配信は受け取らない。」を選んで保存します。

Q登録した覚えがないのにAmazonビジネスのメールが届きます。どうすればよいですか？

Aこの記事は登録済みの方向けです。登録していないのに届く場合は、関連記事 /articles/scout-2026-09-16-7/ をご覧ください。
