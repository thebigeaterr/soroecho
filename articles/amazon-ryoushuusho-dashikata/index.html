Amazonの領収書の出し方｜スマホ・パソコンでの印刷とPDF保存

Amazonの領収書は、注文履歴から出します。パソコンのブラウザで操作するのが基本で、スマホでもアプリではなくブラウザなら出せます。

最短の流れ

  1. 注文履歴を開く
  2. 該当の注文の「領収書等」を選ぶ
  3. 「領収書／購入明細書」を選ぶ
  4. ブラウザの印刷機能で、紙に印刷するかPDFで保存する

つまずきやすい点は3つです。

  • Amazonショッピングアプリからは印刷できない
  • 商品が発送されるまでは、注文履歴に表示されない
  • 支払い方法によっては、領収書が注文履歴で発行されない

この記事の手順と注意点は、Amazonの公式ヘルプ（2026年10月1日に確認）に沿っています。画面の表示名は変わることがあります。

スマホの方は「スマホで領収書を出す手順」へ、表示されない方は「領収書が表示されない・出せないときの原因」へ進んでください。

パソコンで領収書を出す手順

パソコンのブラウザで、Amazonにログインして操作します。

  1. Amazonの「注文履歴」を開く
  2. 領収書が必要な注文を探し、「領収書等」を選ぶ
  3. 表示されたメニューから「領収書／購入明細書」を選ぶ
  4. 領収書が開いたら、ブラウザの印刷を使う

4の印刷画面で、プリンタの代わりに「PDFに保存」などを選べば、PDFで残せます。この選択肢の名前はブラウザによって異なります。

Amazonでは、セキュリティ上の理由から、領収書の印刷と郵送を承っていません。ここでいう「印刷」は、自分のブラウザから出力することです。Amazonが紙の領収書を送ってくれるわけではない点に注意してください。

領収書は、「領収書／購入明細書」のリンクから何度でも再発行できます。保存し忘れても、同じ手順で出し直せます。

スマホで領収書を出す手順

スマホから出すときは、アプリではなく、ブラウザでAmazonのモバイルウェブサイトを開きます。

公式ヘルプでは、Amazonショッピングアプリから領収書／購入明細書を印刷することはできないと案内されています。スマホで「できない」と感じる原因の多くはここです。

iPhone（iOS）の場合

  1. Safariで、Amazonの注文履歴から領収書／購入明細書を表示する
  2. 共有メニューを開き、共有アイコンを選ぶ
  3. プリントアイコンを選ぶ
  4. プリンタを選んで印刷する

Androidの場合

  1. Chromeアプリで、Amazonの注文履歴から領収書／購入明細書を表示する
  2. 右上のその他アイコンから「共有」を選ぶ
  3. 「印刷」を選ぶ
  4. 画面上部でプリンタを選んで印刷する

印刷の方法は、端末やブラウザによって異なります。上の手順どおりの画面が出ないときは、お使いの端末の印刷機能に合わせて読み替えてください。

モバイルウェブでも、一部の注文は印刷の対象外です。アプリを使っている場合や、モバイルウェブで印刷できない注文は、パソコンのサイトの注文履歴から印刷します。

広告

Amazonビジネス

法人・個人事業主向けのAmazonアカウント

請求書払いや数量割引など、通常のAmazonアカウントにはない機能が使えます。登録は無料です（詳細は公式サイトの案内に基づきます）。

Amazonビジネスの登録ページへ（公式）

領収書が表示されない・出せないときの原因

「領収書等」のリンクが見当たらない、領収書が開けない、というときは、次の順に確認してください。

1. まだ商品が発送されていない

領収書等は、注文した商品が発送されると、注文履歴に表示されます。発送されるまでは、閲覧も印刷もできません。

発送の連絡を待ってから、もう一度注文履歴を開いてください。

2. アプリで操作している

先に書いたとおり、アプリからは印刷できません。ブラウザでAmazonを開き直してください。

3. 支払い方法がコンビニ払い・ATM払いなど

コンビニ払い、ATM払い、ネットバンキング払い、電子マネー払いの注文では、領収書が注文履歴では発行されません。詳しくは次の節で説明します。

4. 注文のステータスによる制限

公式ヘルプには、注文のステータスによっては領収書等を閲覧・印刷できない場合があると書かれています。上の1〜3に当てはまらないときは、注文のステータスを確認し、必要ならAmazonのカスタマーサービスに問い合わせてください。

支払い方法ごとの領収書の扱い

領収書が注文履歴で発行されるかどうかは、支払い方法によって変わります。

支払い方法 領収書の扱い
クレジットカード、携帯決済、あと払い（ペイディ）、PayPay、Amazonギフトカード、Amazonポイント、パートナーポイント、メルペイ、au PAY 注文履歴で領収書が発行される
コンビニ払い、ATM払い、ネットバンキング払い、電子マネー払い 各支払い窓口が発行する受領書などを使う。購入明細書とインボイス（適格請求書）は注文履歴から確認できる
請求書払い（Amazonビジネスの場合） 銀行振込控をもって領収書に代える

経費精算で領収書が必要になりそうなら、支払い方法は注文前に選んでおくのが確実です。コンビニ払いにしてから「領収書が出ない」と気づくと、支払い窓口の受領書を保管しておく必要があります。

請求書払いは、Amazonビジネスの支払い方法のひとつです。仕組みと審査については、Amazonビジネスの請求書払いとはで整理しています。

出品者から買った商品の領収書

Amazon.co.jpからの購入でも、マーケットプレイスの出品者からの購入でも、注文履歴に印刷できる領収書が表示されます。

出品者から買った商品の領収書では、出品者名が発行者として印刷されます。発行者がAmazonでないのは、販売元が出品者だからです。

経費精算で発行者名を聞かれたときに備えて、注文詳細で販売元を確認しておくと説明しやすくなります。

領収書の宛名・社判・郵送について

宛名

個人のAmazonアカウントで、領収書の宛名を変更できるかどうかは、公式ヘルプでは案内が見つかりませんでした。自分で宛名を書き換えるのはおすすめしません。宛名が必要なときは、注文前にAmazonのカスタマーサービスへ確認してください。

参考として、国税庁の説明では、不特定多数に販売する小売業などが交付する簡易インボイスは、宛名を省略してよいとされています。宛名のない領収書が、すぐに不備になるとは限りません。経理の扱いは、勤務先の経理担当者や税理士に確認してください。

社判

Amazon・出品者のどちらの領収書も、社判の捺印は承っていません。社判が必須の取引先には、別の書類で対応できないか、先方に確認してください。

郵送

Amazonでは、領収書の郵送も承っていません。自分で印刷するかPDFで保存して使います。

領収書をインボイス（適格請求書）として使うとき

注文履歴に表示される印刷可能な支払い明細書は、経費報告書に使える正式な適格請求書（または区分記載請求書）だと、公式ヘルプに書かれています。

適格請求書を印刷するときは、注文履歴から該当注文の「領収書等」を開き、「明細書／適格請求書」を選びます。この表示が出るのは、次のどちらかの場合です。

  • 販売元がAmazon.co.jp
  • 出品者が適格請求書発行事業者で、登録番号をAmazonに登録している

出品者の商品は、Amazonビジネスのビジネスアカウントを除き、出品者が登録番号を発行しているかどうかを、出品者に直接問い合わせる必要があります。購入前の確認が勧められています。

国税庁は、書類の名称ではなく所定の事項が記載されているかでインボイスになるかを判断し、領収書や納品書でもインボイスになり得ると説明しています。制度の考え方と確認のしかたは、Amazonの領収書はインボイスとして使えるかにまとめています。

Amazonプライム会費の領収書

プライム会費の領収書は、注文履歴とは別の場所にあります。

  1. Amazonプライム会員情報を開く
  2. 「支払い方法の変更」を選ぶ
  3. 「印刷可能な領収書をすべて表示する」を選ぶ
  4. 該当の請求のレシートを表示し、印刷する

プライム会費の適格請求書が必要なときは、注文履歴のキーワード検索で「プライム」と入力し、該当の注文を開いて、先ほどと同じ手順で「明細書／適格請求書」を選びます。

経費精算で毎月たくさん出す人へ

ここまでの手順は、個人のAmazonアカウントのままで使えます。月に数件程度なら、注文ごとに領収書を出す方法で十分です。

一方、買い物が増えて、経費精算のたびに何十件も領収書を開く状態になると、手間が目立ってきます。個人アカウントで複数注文の領収書をまとめて取得する方法は、公式ヘルプでは案内が見つかりませんでした。

そのような場合に検討できるのが、法人・個人事業主向けの購買サービス、Amazonビジネス（登録無料）です。Amazonビジネスの公式ブログでは、次の点が案内されています。

  • 複数の購買を1つのビジネスアカウントにまとめられる
  • 領収書を都度ではなく、まとめて発行できる
  • 領収書を電子データでダウンロードでき、印刷もできる
  • 請求書払いを使うと、複数の購買を1つの請求書にまとめられる（招待制で、審査あり）

適格請求書については、Amazonビジネスのビジネスアカウントに限り、検索フィルタで適格請求書の発行対象が含まれる商品に絞り込めます。商品詳細ページで「適格請求書の発行対象です」と表記された商品を買えば、注文履歴から適格請求書をダウンロードできると、公式ヘルプに書かれています。

請求書払いでは、領収書の代わりに銀行振込控を使う点は、先の表のとおりです。

先に断っておくと、たまにしか領収書が要らない方まで、Amazonビジネスに切り替える必要はありません。経費精算の件数が多く、領収書を集める作業に時間を取られている方向けの選択肢です。

領収書と納品書・見積書の違い

経理や取引先から求められる書類は、領収書とは限りません。

  • 領収書: 支払いを済ませた証明
  • 納品書: 商品を納めた記録（Amazonの納品書の扱いはAmazonの納品書は同梱される？ダウンロードできる？を参照）
  • 見積書: 購入前の金額の提示（Amazonの見積書の出し方を参照）

3つの違いは、見積書・納品書・請求書の違いにもまとめています。

領収書の保存について

領収書は、出して終わりではなく、保存しておく必要があります。PDFで残す場合は、電子帳簿保存法の扱いも関わります。保存期間や電子データでの残し方は、領収書の保存と電子帳簿保存法への対応で整理しています。

Amazonビジネスの公式ブログでは、領収書をPDFなどの電子データで保存する場合も、確定申告の期限日を起点に7年間の保存義務があると説明されています。ご自身の区分（個人か法人か、青色か白色か）で期間が変わるため、迷うときは税務署か税理士に確認してください。

まとめ

Amazonの領収書は、注文履歴の「領収書等」から「領収書／購入明細書」を開き、印刷かPDFで保存します。

  • アプリからは印刷できないので、スマホではSafariやChromeのブラウザで操作する
  • 商品が発送されるまでは、領収書は表示されない
  • コンビニ払い、ATM払いなどでは、領収書は注文履歴で発行されない
  • 出品者の商品は、出品者名が発行者になる
  • 社判の捺印と郵送は承っていない。再発行は何度でもできる
  • 宛名の変更と、個人アカウントでの一括取得は、公式ヘルプで案内が見つからなかった

経費精算で領収書を毎月たくさん出す方は、Amazonビジネス（登録無料）でまとめて取得できるか確認してみてください。

よくある質問

Qスマホから領収書を出せないのはなぜですか？

AAmazonショッピングアプリからは、領収書／購入明細書を印刷できないためです。公式ヘルプでは、スマホではモバイルウェブサイトから操作するよう案内されています。iPhoneならSafari、AndroidならChromeでAmazonにログインし、注文履歴から開いてください。アプリの場合、およびモバイルウェブで印刷の対象外になる注文は、パソコンのサイトの注文履歴から印刷します。

Q領収書が注文履歴に表示されないのはなぜですか？

A多いのは、まだ商品が発送されていない場合です。公式ヘルプでは、領収書等は商品が発送されると注文履歴に表示され、発送前は閲覧も印刷もできないと案内されています。支払い方法がコンビニ払い・ATM払い・ネットバンキング払い・電子マネー払いの場合も、領収書は注文履歴では発行されません。

Q領収書の宛名は変更できますか？

A個人アカウントで宛名を変更する方法は、公式ヘルプでは案内が見つかりませんでした。宛名が必要なときは、注文前にAmazonのカスタマーサービスで確認してください。なお、領収書への社判の捺印は、Amazon・出品者のどちらも承っていません。

Q領収書は何度でも出し直せますか？

A注文履歴の「領収書／購入明細書」のリンクから、何度でも再発行できると公式ヘルプに書かれています。紛失したときも、同じ手順で出し直せます。なお、Amazonでは領収書の郵送は承っていません。

Q複数の注文の領収書をまとめて出せますか？

A公式ヘルプで案内されているのは、注文ごとの手順です。個人アカウントで複数注文をまとめてダウンロードする方法は、公式ヘルプでは見つかりませんでした。月に何件も必要な場合は、まとめて取得できるとされているAmazonビジネス（登録無料）を検討してください。
