結論：アプリでは印刷できない。スマホのブラウザで開き、PDFか印刷にする

Amazonの公式ヘルプ（2026年11月8日確認）は、Amazonショッピングアプリからは領収書／購入明細書を印刷できないと案内しています。iPhoneならSafari、AndroidならChromeでAmazonにログインし、注文履歴から開きます。

Amazonの公式ヘルプで確認できたのは印刷の手順までで、PDFにする操作はAppleとGoogleの公式ヘルプにあります。スクリーンショットで経理に出してよいかは、会社員なら会社のルール、事業者なら国税庁の一問一答の範囲で考えます。

やること iPhone（Safari） Android（Chrome）
開く 注文履歴 →「領収書等」→「領収書／購入明細書」 同じ
印刷 共有 →「プリント」→ プリンタを選ぶ 「その他」→「共有」→「印刷」→ プリンタを選ぶ
PDF保存 ページメニュー →「共有」→「マークアップ」→「完了」→「ファイルを保存」 印刷の画面で、プリンタの選択を「PDF として保存」にする

アプリは使わず、ブラウザでAmazonを開き直す

アプリでは、領収書／購入明細書も、明細書／適格請求書も印刷できません（公式ヘルプ）。次の順でブラウザに移ります。

  1. SafariまたはChromeでAmazonにログインし、アカウントサービスから注文履歴を開く
  2. 該当の注文の「領収書等」を選ぶ
  3. 「領収書／購入明細書」を選ぶ（適格請求書が要るときは「明細書／適格請求書」。出るのは条件に合う注文だけです）

領収書等は、商品が発送されると注文履歴に表示されます。発送前は閲覧も印刷もできません。パソコンの手順や再発行などは、Amazonの領収書の出し方にあります。

iPhoneとAndroidで、領収書を開いて印刷する

Amazonの公式ヘルプにある手順です。印刷の方法は端末やブラウザで異なると注記されています。

iPhone（Safari）

  1. Safariで、注文履歴から印刷する領収書／購入明細書を表示する
  2. 共有メニューを表示し、共有アイコンを選ぶ
  3. 表示されたメニューの「プリント」を選ぶ
  4. プリンタを選んで印刷する

Appleのユーザガイドでは、共有はページメニューのボタンから選びます（「タブレイアウト」が「下」または「上」のときは共有ボタン）。「プリント」が見えなければ、上にスワイプします。

Android（Chrome）

  1. Chromeアプリで、注文履歴から印刷する領収書／購入明細書を表示する
  2. 右上の「その他」アイコンから「共有」を選ぶ
  3. 「印刷」を選ぶ
  4. 画面上部でプリンタを選び、印刷する

スマホのブラウザで「領収書」が見つからないときは？

「領収書」の項目が出ないときは、発送済みか、支払い方法がコンビニ払い・ATM払い・ネットバンキング払い・電子マネー払いではないかを見ます。切り分けは表示されない・出ないときに、「請求書」「明細書」の名前しか無いときは請求書しかないときにあります。

対象外の注文は、PCサイトから

確認した公式ヘルプには、モバイルウェブでも「一部対象外のご注文があります」とあるだけで、条件は書かれていません。対象外のときは、PCサイトの注文履歴から印刷するよう案内されています。

パソコンが無いときは、スマホのブラウザのPC向け表示が使えるかもしれません。Safariはページメニューの「デスクトップ用ウェブサイトを表示」（利用できる場合）、Chromeはその他アイコンの「PC 版サイト」です（Apple・Googleのヘルプ）。

ただ、Amazonの公式ヘルプにはこの方法の記載が見つからず、印刷・保存できるかは確認できていません。

「注文の詳細」しか開かない、という報告

パソコンで「領収書／購入明細書」を選んでも「注文の詳細」や「印刷可能な注文概要」しか開かない、という利用者の報告が2025年6月ごろから続いています（Yahoo!知恵袋の2025年6〜9月の質問、2025年11月のニュースサイト、2026年11月の個人ブログなど）。

スマホのブラウザなら従来の領収書が出た、という報告もあります（Yahoo!知恵袋の2025年6月の質問など）。これらの名前は、2026年11月8日時点の公式ヘルプには記載が見つかりませんでした。

領収書をPDFで保存するには？

公式ヘルプの「領収書が欲しい」には「印刷およびダウンロード可能な領収書」とありますが、ダウンロードやPDF保存の手順は見つかりませんでした。案内されているのは印刷オプションでの印刷です。PDFにする操作は、AppleとGoogleの公式ヘルプにあるスマホの機能を使います。

iPhone：Safariの「ファイルを保存」

Appleのユーザガイドの手順です。

  1. 領収書／購入明細書を開き、ページメニューのボタンから「共有」をタップする
  2. 「マークアップ」をタップする
  3. 「完了」をタップし、「ファイルを保存」を選ぶ
  4. 名前を入力して「保存」をタップする

領収書には書き込みをせず、そのまま「完了」をタップします。

Android：Chromeの「PDF として保存」

Googleのヘルプの手順です。

  1. 領収書／購入明細書を開き、右上の「その他」アイコンから「共有」「印刷」と進む
  2. 画面上部のプリンタの選択で「PDF として保存」をタップする
  3. 端末内の保存場所を選び、「印刷」をタップする

保存先は、保存のときに選んだ場所です。「日付_Amazon_金額」のような名前にすると探しやすくなります。

開いて、日付・金額・発行者・宛名を確かめてください。宛名はAmazonの領収書の宛名変更にまとめています。失敗しても、何度でも再発行できます（公式ヘルプ）。

スマホから印刷するには？自宅のプリンタとコンビニ

Amazonは、セキュリティ上の理由で領収書の印刷も郵送も承っていません（公式ヘルプ）。紙が要るときは、自分で印刷します。

自宅のプリンタは、iPhoneならAirPrint対応のものを、iPhoneと同じWi-Fiにつなぎます（Appleのユーザガイド）。Androidは、Wi-Fiまたはモバイルネットワーク経由でデータを受け取れるプリンタを追加します（Googleのヘルプ）。

コンビニには、ファイルを送って店のコピー機で出すネットプリントなどのサービスがあります。料金、対応するファイルの形式、受け取りの手順は運営会社ごとに違うため、使うコンビニの公式案内で確かめてください。

毎月何十件も出す人は、一括ダウンロードの記事も見てください。

経理に提出するには？メール・経費精算・スクリーンショット

提出の形を決めるのは、会社員なら会社の経理、事業の領収書なら国税庁のルールです。以下は、国税庁の電子帳簿保存法一問一答【電子取引関係】（令和8年7月）の範囲で整理しました（「問」は問番号）。

会社員：渡す形は会社が決める

問12は、従業員が会社の経費を立て替えて電子データの領収書を受け取る行為を、会社としての電子取引としています。

会社が集めて保存・管理するのが望ましく、集めるまでの間は、会社が日付・金額・取引先で保存状況を管理していれば、従業員のスマホにデータを置いたままでもよいとされています。

問36には、従業員がスマホのアプリで経費を立て替えた場合の例として、画面の領収書データをメールで送らせて保存する方法があり、「いわゆるスクリーンショットによる領収書の画像データでも構いません」と書かれています。ただ、経費精算が画像やメール添付を受け付けるかは会社が決めます。経理には、こう聞くと早いです。

Amazonの領収書をスマホのブラウザから取りました。PDFを経費精算に添付する形でよいですか。スクリーンショットでも受け付けてもらえますか。精算後に手元のPDFを消してよいかも教えてください。

個人事業主・法人：データのまま保存する

個人事業者や法人は、電子取引で受け取った領収書のデータを保存しなければなりません（問1）。問5は、ダウンロードしたPDFも、画面のスクリーンショットも電子取引としています。

保存の例は問36にあります。HTMLで表示される領収書は、スクリーンショットを保存する方法や、HTMLのデータをPDF等の形式に変換して保存する方法などです。

保存先は、あとから表示・検索できること（可視性）と、改ざんを防ぐ措置（真実性）の要件を満たす必要があります。

国税庁はAmazonの画面を名指ししていないため、自分の場合にあてはまるかは、税理士か税務署に確認してください。

個人事業主の例として、問19は、ファイル名に日付・取引先・金額を入れ（例：20210131_㈱霞商店_110000）、フォルダで分け、事務処理規程を定めて運用する方法を挙げています。

スマホだけで取引する人向けに、問21は、プリンタが無くても近隣の有料プリンタ等で速やかに出力できれば備え付けと扱ってよいとしています。機種変更では、データを新しい端末に移すか、古い端末を動く状態で残す対応などが必要になるとあります。

印刷した紙があっても、データは残す

データを要件どおりに保存したうえで、書面に出力して他の書類と一緒に整理することは問題ありません（問31）。一方、出力した書面は保存書類として扱われず（問5）、その紙をスキャナで読み取って保存することも認められません（問99）。

紙の領収書を読み取る「スキャナ保存」は別の制度で、領収書のスキャン保存と電子帳簿保存法で解説しています。

消費税の仕入税額控除は別で、電子インボイスを整然とした形式・明瞭な状態で出力した書面の保存でも受けられるとされています（問5）。

スマホで領収書を出すときのチェックリスト

  • アプリではなくブラウザで、発送済みの注文の「領収書等」から「領収書／購入明細書」を開いた
  • PDFにして保存し、日付・金額・発行者が読めることを確かめた
  • 経理に、PDF・スクリーンショット・紙のどれが要るかを聞いた
  • 事業の領収書は、PDFを消さず、ファイル名のルールを決めて残した（紙に印刷しても同じ）

まとめ

スマホでAmazonの領収書を出すには、アプリではなくブラウザを使います。印刷は公式ヘルプの手順で、PDFにする操作はAppleとGoogleの公式ヘルプにあるスマホの機能で行います。

経理に出す形は、会社員なら会社が決めます。事業の領収書は、電子データを要件に沿って保存することが、国税庁の一問一答で求められています。個別の判断は、税理士か税務署に確認してください。

よくある質問

QAmazonのアプリから領収書を印刷できますか？

Aできません。Amazonの公式ヘルプ（2026年11月8日確認）は、Amazonショッピングアプリからは領収書／購入明細書を印刷できないと案内しています。iPhoneはSafari、AndroidはChromeでAmazonにログインし、注文履歴の「領収書等」から「領収書／購入明細書」を開いて印刷します。モバイルウェブで印刷の対象外になる注文は、PCサイトの注文履歴から印刷します。

QスマホでAmazonの領収書をPDFにして保存するには、どうしますか？

AAmazonの公式ヘルプには、PDFで保存する手順は見つかりませんでした。iPhoneは、Appleのユーザガイドにあるとおり、Safariのページメニューから「共有」「マークアップ」「完了」と進み、「ファイルを保存」を選びます。Androidは、Googleのヘルプにあるとおり、Chromeの印刷画面でプリンタの選択を「PDF として保存」にし、保存場所を選びます。

Qスクリーンショットの領収書は、経費精算や帳簿に使えますか？

A会社の経費精算で受け付けるかは、会社のルールで決まります。事業の帳簿書類については、国税庁の電子帳簿保存法一問一答（電子取引関係、令和8年7月）の問36に、ウェブサイトにHTMLで表示される領収書について、スクリーンショットを保存する方法や、PDF等に変換して保存する方法が例示されています。保存先は真実性と可視性の要件を満たす必要があり、個別の判断は税理士か税務署に確認してください。

Qコンビニで領収書を印刷できますか？

AAmazonでは、セキュリティ上の理由で領収書の印刷も郵送も承っていません（公式ヘルプ）。コンビニで紙にするなら、スマホで領収書をPDFなどのファイルにしてから、コンビニのネットプリントなどの印刷サービスを使います。料金、対応するファイルの形式、受け取りの手順は運営会社ごとに違うため、各社の公式案内で確かめてください。

QAmazonで何度でも再発行できるなら、PDFに保存しなくてもよいですか？

A公式ヘルプは、領収書／購入明細書のリンクから何度でも再発行できると案内しています。国税庁の一問一答（問45）には、ECサイト上で領収書等のデータをいつでも確認できる場合は、必ずしもダウンロードして保存しなくてよいとする扱いがあります。ただし、ECサイト側が真実性の確保と検索機能の確保の要件を満たしていることが前提で、保存期間が終わる前にサイトで確認できなくなる場合は、その前にダウンロードして保存する必要がある、とされています。Amazonがこれにあたるかは公式ヘルプでは確認できなかったため、事業の領収書は自分で保存しておくのが確実です。
