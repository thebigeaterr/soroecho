結論：見分け方は、通常アカウントとビジネスアカウントで違う

Amazonでインボイス（適格請求書）が出る商品かどうかの見分け方は、使っているアカウントで変わります。

通常のアカウントでは、出品者が登録番号を持っているかを、画面から確かめる方法がありません。Amazon公式ヘルプでは、出品者に直接問い合わせる必要があるとされ、購入前の問い合わせが勧められています。

Amazonビジネスのビジネスアカウントなら、画面で見分けられます。検索結果のフィルタで「発行対象が含まれる商品」を選び、商品詳細ページに「適格請求書の発行対象です」と表記された商品を買う流れです。

この記事では、次の順に整理します。

  • 通常アカウントとビジネスアカウントの違い（表）
  • 販売元がAmazonの場合と出品者の場合の違い
  • 適格請求書と支払い明細書の違い
  • 管理者が対象外の出品を制限する手順
  • パソコン・スマホでの印刷手順

税金の判断はこの記事では行いません。公式ヘルプでも、Amazonは顧客の消費税還付の適格性を評価できないと案内されています。分からない場合は税理士に相談してください。

通常アカウントとビジネスアカウントの違い（一覧）

先に、違いを表にまとめます。

項目 通常アカウント ビジネスアカウント
購入前に見分ける方法 出品者の登録番号の有無は、出品者に直接問い合わせる（購入前の問い合わせが勧められている） 検索フィルタ「発行対象が含まれる商品」で絞り込み、商品詳細ページの「適格請求書の発行対象です」の表記を見る
書類の取り方 注文履歴の「領収書等」から「明細書／適格請求書」を開く 注文履歴、または購買データからダウンロードする
スマホアプリで印刷できるか できない（モバイルのブラウザからは可能） 通常アカウントと同様、ショッピングアプリからは印刷できない
対象外の出品を制限できるか ビジネスアカウントの機能 管理者が購買ルールで制限・絞り込みできる

アカウントの違いを詳しく知りたいときは、Amazonビジネスと個人アカウントの違いを見てください。

広告

Amazonビジネス

インボイス対応の商品だけに絞り込めるのは、Amazonビジネスのアカウントです（登録無料）

検索結果を「適格請求書発行対象」に絞り込め、インボイスも購買データ画面からまとめてダウンロードできます。個人向けのアカウントでは、この2つは使えません。

Amazonビジネスの登録ページへ（公式）

「販売元がAmazon.co.jp」か「出品者」かで決まる

公式ヘルプでは、注文履歴から適格請求書を確認・印刷できる条件が示されています。販売元で、条件が次のように分かれます。

販売元 注文履歴で適格請求書を確認・印刷できる条件
Amazon.co.jp 該当する
出品者 出品者が適格請求書発行事業者であり、登録番号をAmazonに登録している

つまり、販売元がAmazon.co.jpなら、適格請求書を確認・印刷できます。出品者の場合は、出品者の側が登録番号をAmazonに登録しているかで決まります。

ここが、通常アカウントで見分けにくい理由です。出品者の登録の有無は、通常アカウントの画面には出てきません。だから、購入前に出品者へ問い合わせることが勧められています。

Kindle本は、次のように決まります。

  • 出品者が Amazon Services International LLC の場合、注文履歴から適格請求書をダウンロードできる
  • それ以外の出品者のKindle本は、各出品者が発行する。連絡先は商品詳細ページの出品者情報にある

なお、オンラインコード版ソフトウェアなど課税対象外の商品には、適格請求書は発行されません。

適格請求書と支払い明細書の違い

Amazonビジネスの公式ヘルプでは、出品者の登録番号の有無で、適格請求書か支払い明細書かが決まるとされています。

項目 適格請求書 支払い明細書
出る場合 Amazon、または登録番号を持つ出品者の商品を買ったとき 登録番号をAmazonに提出していない出品者の注文
登録番号 Amazonの登録番号「T3040001028447」を使える。参照用に出品者の登録番号も印刷される Amazonと出品者のどちらの登録番号でも、消費税の還付は受けられない

登録番号「T3040001028447」は、アマゾンジャパン合同会社の登録番号です。Amazonまたは登録番号をAmazonに提出済みの出品者から買ったときに使えます。Amazonは仲介者として特別規定を適用しています。

適格請求書に受取人の会社名・団体名が含まれない場合は、適格簡易請求書として使用できます。

保管についても、公式ヘルプに記載があります。Amazonビジネスの顧客の適格請求書は、発行日（商品の発送日）から10年間、Amazonに保管されます。書類は、注文の発送後にダウンロードできます。

支払い明細書しか出ないとき

支払い明細書が出たときは、その注文ではAmazonの登録番号も出品者の登録番号も使えません。消費税の扱いは個別の事情で変わるため、断定はできません。公式ヘルプも、分からない場合は税理士に相談するよう案内しています。

次回から避けたいときは、購入前に出品者へ問い合わせるか、ビジネスアカウントで対象を絞り込む方法があります。

国税庁が示す適格請求書の記載事項

参考として、国税庁のインボイス制度の説明ページで示されている、適格請求書に書くべき事項を挙げます。

  • 発行した事業者の氏名または名称と、登録番号
  • 取引した年月日
  • 取引の内容（軽減税率の対象なら、その旨）
  • 税率ごとに合計した金額と、適用される税率
  • 税率ごとの消費税額
  • 書類を受け取る側の氏名または名称

登録番号は「T」に続く13桁の数字です。小売業などでは、受け取る側の名前の記載を省ける簡易な形式が認められる場合があります。詳しい範囲は国税庁のページで確認してください。

Amazonビジネスの登録ページへ（公式）

ビジネスアカウントで対象外の出品を絞り込む

ビジネスアカウントの管理者は、購買ルールで、登録番号のない販売者の商品を制限または絞り込めます。Prime Businessに登録していない顧客も使えます。

設定の手順

公式ヘルプに書かれている手順は次のとおりです。

  1. ビジネスアカウントの設定を開く
  2. 「購入ポリシー」の「購入ポリシーと承認」を開く
  3. 「販売者に関する購買ルール」で、次のどちらかを選ぶ
    • 制限ルール：適格請求書発行対象外の出品
    • 絞り込みルール：適格請求書発行対象の出品
  4. ルール名、購買依頼者へのメッセージ、管理者へのメッセージを入力する
  5. 制限ルールの場合は、承認ワークフローと承認者を設定する
  6. 適用範囲を選ぶ（現在のグループのみ、またはサブグループも）
  7. 保存する

設定後は、対象外の商品に「組織が制限されている」「組織がブロックされている」と表示されます。

買う前に確認するときの手順

通常アカウントの場合

  1. 商品ページで、販売元を確認する
  2. 販売元がAmazon.co.jpなら、注文履歴から適格請求書を確認・印刷できる条件に該当する
  3. 出品者の場合は、購入前に出品者へ、登録番号を持っているかを問い合わせる

ビジネスアカウントの場合

  1. 検索結果のフィルタで「発行対象が含まれる商品」を選ぶ
  2. 商品詳細ページで、「適格請求書の発行対象です」と表記された商品かを見る
  3. 購入し、発送後に注文履歴または購買データから適格請求書をダウンロードする

商品詳細ページでは、表記がカートに入れるボタンの下にあります。

適格請求書を印刷する手順

パソコンの場合

  1. 注文履歴を開く
  2. 該当の注文の「領収書等」を選ぶ
  3. 「明細書／適格請求書」を選ぶ
  4. ブラウザの印刷機能で印刷またはPDF保存する

プライム会費の適格請求書

注文履歴のキーワード検索に「プライム」と入力して検索します。出てきた注文から、上の手順と同じ流れで印刷します。

Businessプライムの会費の適格請求書は、「お支払い履歴」ページからダウンロードできます。

スマホの場合

Amazonショッピングアプリからは、明細書／適格請求書を印刷できません。モバイルのブラウザからは、次の方法があります。

端末 手順
iOS Safariで開き、共有メニューから「プリント」を選ぶ
Android Chromeで開き、右上の「その他」から「共有」、印刷の順に選ぶ

一部の注文は、モバイルサイトからの印刷の対象外です。その場合は、パソコンのサイトから印刷してください。

領収書そのものの出し方は、Amazonの領収書の出し方で、パソコン・スマホ別に説明しています。

複数の注文をまとめて取りたいとき

ビジネスアカウントでは、購買データの「注文履歴データ」で「注文関連書類をダウンロードする」を使うと、一度に最大2,000の請求書をダウンロードできます。

期間の指定や、3つの取り方の比べ方は、Amazonビジネスの領収書を一括でダウンロードする方法にまとめています。

請求書払いを使っている場合、請求書払いの請求書は適格請求書として使えます。取り方はAmazonビジネスの請求書払いで説明しています。

注文前に金額を示すための見積書は、領収書や請求書とは別の書類です。出し方はAmazonの見積書の出し方を見てください。

経費精算で確認すること

書類が手元に来たら、経費精算の前に次の点を見ます。

  1. 事業用の購入か、私用の購入かを分ける
  2. 書類の種類が、適格請求書か支払い明細書かを確認する
  3. 登録番号（T+13桁）と、税率ごとの消費税額が載っているかを見る
  4. 宛名が自分（または自社）になっているかを見る
  5. 帳簿や会計ソフトに、日付・金額・内容・支払先を記録する

宛名は、発行時の情報で決まるのが基本です。書類が出たあとに手書きで直すのは避けてください。訂正が必要な場合は、発行元に相談します。

インボイスが必要になるのは、主に仕入れの消費税を差し引く場面です。課税事業者か免税事業者かなど、ご自身の区分によって扱いが変わります。保存の方法や期間も同じです。国税庁の案内を見るか、税務署や税理士に確認してください。

登録番号が本物かを確かめたいときは、国税庁の公表サイトで検索する方法があります。入口は国税庁のインボイス制度のページから探せます。

書類が足りないときの対処

登録番号がない、税額が分からない、宛名が違う。そんなときは、次の順で動きます。

  1. 販売元がAmazonか出品者かを再確認する
  2. ビジネスアカウントなら、注文履歴と購買データの両方から適格請求書を探す
  3. 出品者の商品なら、出品者に問い合わせる
  4. それでも足りない場合は、税理士や税務署に扱いを確認する

インボイスがない購入分でも、経費として記録すること自体はできる場合があります。ただし、消費税の計算での扱いは変わる可能性があります。個別の判断は専門家に相談してください。

確認日時点の情報に基づく整理です。画面や制度は変わることがあるため、最新の内容は公式ページで確認してください。

よくある質問

Q出品者が売っている商品は、インボイスが出るかどうか見分けられますか？

A通常のアカウントでは、画面だけでは見分けられません。Amazon公式ヘルプによると、出品者が登録番号を持っているかは出品者に直接問い合わせる必要があり、購入前の問い合わせが勧められています。ビジネスアカウントなら、検索フィルタの「発行対象が含まれる商品」と、商品詳細ページの「適格請求書の発行対象です」という表記で見分けられます。

Q適格請求書ではなく「支払い明細書」しか出ないのはなぜですか？

A出品者の登録番号の有無で、適格請求書か支払い明細書かが決まります。登録番号をAmazonに提出していない出品者の注文には、支払い明細書が発行されます。公式ヘルプでは、その場合はAmazonと出品者のどちらの登録番号でも消費税の還付を受けられないと案内されています。

Q領収書に載っている「T3040001028447」とは何の番号ですか？

Aアマゾンジャパン合同会社の登録番号です。Amazonまたは登録番号をAmazonに提出済みの出品者から買った場合、この番号を使えます。Amazonは仲介者として特別規定を適用しています。参照用に、出品者の登録番号も印刷されます。

QスマホのAmazonアプリから、適格請求書を印刷できますか？

AAmazonショッピングアプリからは印刷できません。スマホのブラウザでAmazonのモバイルサイトを開き、iOSならSafariの共有メニューから「プリント」、AndroidならChromeの「その他」から「共有」、印刷の順に進みます。一部の注文は対象外で、その場合はパソコンのサイトから印刷します。

Q適格請求書の保管期間は何年ですか？

AAmazonビジネスの顧客の適格請求書は、発行日（商品の発送日）から10年間Amazonに保管されます。オンラインコード版ソフトウェアなど課税対象外の商品には、適格請求書は発行されません。
