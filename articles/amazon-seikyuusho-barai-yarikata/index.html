結論：通常アカウントのままでは難しく、事業者用アカウントで申し込む

Amazonで月まとめの請求書払い（後払い）を使いたい場合は、事業者向けのアカウントを作って申し込むのが基本です。通常の個人向けアカウントの支払い方法とは、別の仕組みとして考えてください。

請求書払いには審査があります。申し込めば必ず使えるわけではありません。

この記事は、サービス名を知らない人が「何をどの順で進めるか」をつかむための入口です。サービス自体の詳しい解説は、別記事のAmazonビジネスの請求書払いの解説にまとめています。

あなたの場合はどうなるか

あなたの状況 進め方の目安
法人（会社）で購入する 法人として事業者用アカウントを作り、請求書払いを申し込む
開業届を出した個人事業主 個人事業主として登録し、審査の結果を見て支払い方法を決める
開業届をまだ出していない 開業届は必須ではないが、確認書類を1点提出する（確定申告書Bなども可）。用意できるか確認し、請求書払いは審査の結果を見て決める
審査に通らなかった カード払いなどに切り替え、月ごとの購入額を整理して再検討する

請求書払いとは何か：カード決済との違い

請求書払いとは、購入のたびに払わず、一定期間の購入分をまとめて後日支払う方法です。「後払い」「掛け払い」と呼ばれることもあります。

カード決済は、購入ごとにカード会社経由で引き落とされます。請求書払いは、月ごとの請求にまとまるため、支払いの回数が減ります。

請求書払いを選ぶ主な理由

  • 支払いを月1回にまとめ、経理の手間を減らせる
  • 購入者と支払い担当が別でも、請求単位で処理しやすい
  • カードの利用枠を、備品購入で圧迫しにくい

一方で、審査があります。限度額が設けられる場合もあるため、承認後の案内で確認してください。支払い期限を過ぎると信用に響くおそれがあるため、資金繰りの見通しを持って使うことが前提です。

従業員が複数いる場合の考え方

従業員5〜30人の会社では、購入者が複数になりがちです。誰が注文でき、誰が支払いを管理するかを、申込み前に決めておくと運用が安定します。

ひとり社長の場合は、自分が購入者と支払い担当を兼ねるため、支払い日と口座残高の管理だけを押さえれば足ります。

申込みの流れ：5つのステップ

具体的な画面や入力項目は変更されることがあるため、最新の内容はAmazonビジネスの公式ページで確認してください。ここでは全体の流れを示します。

  1. 事業者用アカウントを作る：事業者名、住所、連絡先などを入力します。 [要実演スクショ: 事業者アカウント登録画面]
  2. 事業者情報を登録する：法人か個人事業主かを選び、必要な情報を入力します。
  3. 請求書払いを申し込む：支払い方法の設定画面から、請求書払いの申込みに進みます。 [要実演スクショ: 支払い方法の選択画面]
  4. 審査を待つ：結果が出るまでは、カード払いなど別の方法で買うか、購入を待ちます。
  5. 結果を確認して設定する：承認されたら、締め日などの支払い条件（限度額の案内がある場合はその金額）を画面で確認します。 [要実演スクショ: 審査結果と限度額の表示画面]

申込み前に手元に用意するもの

  • 法人名または屋号、所在地、電話番号
  • 法人の場合は登記上の情報（会社の正式名称や所在地）
  • 個人事業主の場合は、確認書類1点（開業届、過去2年以内の確定申告書B・収支内訳書、インボイスの登録通知書など）
  • 支払い方法の設定に必要な情報（申込み画面の案内に従う）

自宅住所を出したくない場合は、登録する住所が請求書や書類にどう表示されるかを、申込み前に確認してください。バーチャルオフィスなどの住所を使えるかは、審査や規約の条件に関わるため、公式の案内を見て判断します。

審査と限度額の考え方

審査の具体的な基準は公開されていないため、この記事では推測で書きません。

限度額とは、後払いで購入できる上限の金額のことです。公式サイトでは限度額の有無や金額を確認できていないため、設けられている場合は承認後の案内で確認してください。

限度額を決めるために自分で確認すること

限度額が足りるかどうかは、次の手順で見積もれます。

  1. 直近3か月の備品・消耗品の購入額を、月ごとに集計する
  2. 一番多かった月の金額を確認する
  3. 繁忙期や、まとめ買いの予定を上乗せして見込む
  4. 限度額が設けられている場合はその金額と比べ、足りない分はカード払いなどで補う

ネットショップ運営者で月50〜300件を発送する場合は、梱包資材の購入が増えやすいため、発送件数の多い月を基準にすると見誤りにくくなります。

審査に通らなかったときの考え方

通らなかった場合でも、事業が否定されたわけではありません。審査の基準は公開されていないため、理由は推測できません。

その場合は、カード払いで購入を続けながら、条件を確認して改めて申し込む方法があります。申込み条件は変わることがあるため、再申込みの際は公式の案内を確認してください。

支払いサイトと支払い管理

支払いサイトとは、購入から支払い期限までの期間のことです。請求書払いでは、この期間が資金繰りに直接影響します。

公式サイトでは、請求書払いは手数料無料で1か月分の購入代金をまとめて後払いでき、締め日は5日・10日・15日・20日・25日・末日から選べると案内されています。支払い期限の日数などは、承認後の案内で確認してください。この記事では日数を断定しません。

支払い期限で確認したい項目

確認する項目 なぜ大切か
締め日 どの購入が、どの月の請求になるかが決まる
支払い期限 口座に入金しておく日が決まる
支払い方法 銀行振込か、口座からの引き落としかで手間が変わる
振込手数料の負担 実質的なコストに含まれるかを見る

資金繰りの注意点

売上の入金が遅れがちな時期は、支払い期限との間に空白ができます。月末に大きな支払いが重なる場合は、支払日の数日前に残高を確認する習慣をつけてください。

法人口座を開設したばかりの場合は、口座の登録や引き落とし設定に時間がかかることもあります。余裕をもって準備しましょう。

請求書のダウンロードと経理への使い方

請求書や領収書は、注文履歴から表示・保存できます。会計ソフトに取り込む前に、保存の名前や置き場所をそろえておくと、後の作業が楽になります。

画面の項目名は更新されることがあるため、最新の手順は公式ヘルプで確認してください。 [要実演スクショ: 注文履歴から請求書を表示する画面]

保存と整理の基本手順

  1. 注文履歴を開き、対象の注文を選ぶ
  2. 請求書または領収書を表示し、PDFなどで保存する
  3. 「日付_購入先_金額」のように、名前のルールを決めて保存する
  4. 月ごとのフォルダに分け、会計ソフトの取引と照らし合わせる

書類の保存期間は、法人か個人か、帳簿の種類によって異なります。ご自身の場合の期間は、国税庁の案内か税理士に確認してください。

まとめ：自分の場合の進め方

請求書払いは、事業者用アカウントを作り、審査を経て使えるようになる仕組みです。通常アカウントのまま使う前提では考えないでください。

最初の一歩として、次の順で動くと迷いにくくなります。

  1. 直近の購入額を集計し、月の予算を決める
  2. 登録する事業者情報と住所の扱いを決める
  3. 事業者用アカウントを作り、請求書払いを申し込む
  4. 承認後、限度額・締め日・支払い期限を画面で確認する

サービス側の詳しい仕様は、Amazonビジネスの請求書払いの記事もあわせて参照してください。

よくある質問

Q通常のAmazonアカウントで請求書払いはできますか？

A通常の個人向けアカウントの支払い方法は、カードやコンビニ払いなどが中心です。月まとめの請求書払いを使いたい場合は、事業者向けのアカウントを作り、請求書払いを申し込む流れになります。利用できる支払い方法は、申込み画面と公式ヘルプで確認してください。

Q請求書払いには審査がありますか？

Aあります（公式サイトに「審査がございます」と案内されています）。審査の基準は公開されていません。結果は申込み内容で変わるため、通らなかった場合はカード払いなど別の支払い方法を併用する形で考えます。

Q個人事業主でも後払いは使えますか？

A法人だけでなく個人事業主も、事業者向けアカウントの対象に含まれます。登録時に確認書類を1点提出します（開業届のほか、過去2年以内の確定申告書B・収支内訳書、インボイスの登録通知書なども可）。請求書払いの可否は審査次第です。

Q請求書はどこからダウンロードできますか？

A注文履歴の各注文から、請求書や領収書を表示・保存する操作ができます。表示される項目名は画面の更新で変わることがあります。最新の手順は公式ヘルプで確認してください。
