結論：個人アカウントは注文履歴から、Amazonビジネスは発送の24時間後から最大2,000件

公式ヘルプ（2026年11月8日確認）によると、領収書、適格請求書、支払い明細書は、注文が発送されると注文履歴に表示されます。請求書の「発行」を探すときは、まず注文履歴を開きます。

どの書類を開くかは、アカウントと使い道で変わります。個人アカウントの入り口は注文履歴です。アプリでは印刷できず、スマホのブラウザにも対象外の注文があり、その場合はパソコンのサイトの注文履歴から印刷するよう案内されています。

インボイス（適格請求書）が要るときは、該当の注文の「領収書等」から「明細書／適格請求書」を選びます。パッケージの請求書（納品書が同梱されていないときに印刷できる請求書）は、注文履歴の「請求書を表示する」から開きます。公式ヘルプが「経費報告書に使用できる正式な適格請求書（または区分記載請求書）」と案内しているのは、注文履歴に表示される印刷可能な支払い明細書です。

あなたの場合 出す書類 出し方（公式ヘルプの項目名）
個人アカウントで買い、インボイス（適格請求書）が要る 明細書／適格請求書 注文履歴 → 該当の注文の「領収書等」→「明細書／適格請求書」→ ブラウザの印刷。販売元がAmazon.co.jpか、登録番号をAmazonに登録した出品者の注文だけ

個人アカウントで公式ヘルプが案内している手順は、書類を開いて、ブラウザの印刷オプションで印刷するところまでです。ダウンロードボタンの手順は、読んだ範囲に見つかりませんでした。PDFで残したいときは、ブラウザ側の機能を使います。

Amazonは、セキュリティ上の理由で領収書の印刷と郵送を承っていません。紙にするときは、自分で印刷します。

この記事は、買い手として注文した商品の請求書の話です。出品者向けの請求書や、Amazon Web Servicesなど別のサービスの請求書は扱いません。画面の表示や条件は変わることがあり、この記事は公式ヘルプの記載に沿っています（自分のアカウントの画面は見ていません）。

Amazonの「請求書」はどれ？公式ヘルプに出てくる4つの書類

「請求書」の名前で探すと迷います。公式ヘルプには似た書類が複数あり、開く場所も使い道も別です。個人アカウントで読めた範囲を表にします。

書類の名前 開く場所 公式ヘルプでの位置づけ 出る条件
明細書／適格請求書 注文履歴 →「領収書等」 インボイス制度に関するインボイス（適格請求書） 販売元がAmazon.co.jp、または出品者が適格請求書発行事業者で、登録番号をAmazonに登録している
領収書／購入明細書 注文履歴 →「領収書等」 領収書 クレジットカード、携帯決済、ペイディ、PayPay、ギフトカード、ポイントなどの支払い。コンビニ払い・ATM払い・ネットバンキング払い・電子マネー払いでは、Amazonは領収書を発行しない
請求書 注文履歴 →「請求書を表示する」 パッケージの請求書。納品書が同梱されていないときに印刷できる。メーカーに修理を依頼するときなどの、お買い上げ証明に使える 公式ヘルプに条件の記載なし
支払い明細書 注文履歴（各注文） 経費報告書に使用できる正式な適格請求書（または区分記載請求書） 注文が発送されると表示される

「請求書を表示する」で開く書類が、適格請求書にあたるかどうかは、読んだ公式ヘルプに書かれていません。公式が適格請求書として案内しているのは、「明細書／適格請求書」と、注文履歴の支払い明細書です。

メニューの名前と書類の呼び名を1対1で結ぶ説明も、見つかりませんでした。経費精算に出す書類の名前をめぐる整理は、Amazonの領収書が「請求書」しかない時にあります。

個人アカウントで請求書を出す手順（パソコン）

インボイス用：「明細書／適格請求書」

公式ヘルプの手順は次の4つです。

  1. 注文履歴にアクセスする
  2. 該当の注文の「領収書等」を選ぶ
  3. 「明細書／適格請求書」を選ぶ
  4. ブラウザの印刷オプションを選んで印刷する

印刷できる条件は、販売元がAmazon.co.jpであること、または販売元が出品者で、その出品者が適格請求書発行事業者であり、登録番号をAmazonに登録していることです。

出品者が登録番号を発行しているかは、Amazonビジネスのビジネスアカウントを除き、出品者に直接問い合わせる必要があります。公式ヘルプは、購入前の問い合わせを勧めています。見分け方はAmazonのインボイス対応の見分け方にあります。

プライム会費の適格請求書は、注文履歴のキーワード検索に「プライム」と入力し、出てきた注文から同じ手順で印刷します。会費の領収書も含めた手順はAmazonプライム会費の領収書・適格請求書にあります。

パッケージの請求書：「請求書を表示する」

納品書が同梱されていないときの手順として、公式ヘルプ「納品書が同梱されていない場合」にあります。

  1. 注文履歴に移動する
  2. ドロップダウンメニューで、適切な日付範囲を選ぶ
  3. 注文を見つけて、「請求書を表示する」を選ぶ
  4. 「このページを記録用に印刷する」を選ぶ（ブラウザの「印刷」ボタンでもよい）

個人アカウントの注文では、Amazon.co.jpが販売する商品に、一部を除き納品書が同梱されません（公式ヘルプ「納品書について」）。メーカーに修理を依頼するときなどは、この請求書をお買い上げ証明として使えると案内されています。

注文は、手順2の日付範囲を選んで探します。古い注文が見つからないときは、日付範囲を切り替えます。納品書の扱いはAmazonの納品書の記事にまとめています。

領収書がほしいとき

「領収書等」から「領収書／購入明細書」を選びます。出品者が販売する商品の領収書には、出品者名が発行者として印刷されます。社判の捺印は、Amazon.co.jpの領収書も出品者の領収書も承っていません（公式ヘルプ「領収書の発行可否、記載内容について」）。

支払い方法で出ない場合や、スマホ・プライム会費の扱いは、Amazonの領収書の出し方にまとめています。

発送前は出ない。支払い明細書は、出荷準備に入ると変更できない

領収書等（領収書、適格請求書または支払い明細書）は、注文が発送されると注文履歴に表示されます。発送までは閲覧も印刷もできません。

支払い明細書の請求先住所は、支払い方法に関連付けられている住所です。公式ヘルプには、アカウントサービスの支払い方法から請求先住所を変更できる、とあります。一方で、注文商品が出荷準備に入ると、支払い明細書の内容は変更できなくなります（公式ヘルプ「支払い明細書について」）。

支払い方法の請求先住所を変えると、注文済みの支払い明細書にも反映されるかは、公式ヘルプに書かれていません。宛名（名前）を変える方法も、今回読んだ個人アカウントの公式ヘルプに見つかりませんでした。Amazonの領収書の宛名変更を見てください。

「ダウンロード」と「印刷」は何が違う？公式の手順はブラウザの印刷まで

「【Q】領収書が欲しい」には、印刷およびダウンロード可能な領収書は注文履歴で表示できる、とあります。ただ、ダウンロードの手順は書かれておらず、手順として案内されているのは、書類を開いてブラウザの印刷オプションで印刷する方法です。やりたいことごとに、公式ヘルプの案内を並べます。

やりたいこと 公式ヘルプの案内
紙にしたい 書類を開き、自分でブラウザから印刷する。Amazonは、セキュリティ上の理由で領収書の印刷と郵送を承っていない
PDFにしたい 手順は書かれていない。印刷画面の保存先でPDFを選べる場合があるが、これはブラウザ側の機能で、端末やブラウザによって名前が違う
もう一度出したい 領収書は「領収書／購入明細書」のリンクから何度でも再発行できる
Amazonビジネスで2回目以降に開く 「領収書／購入明細書」のリンクを2回目以降に選ぶと、請求書発行日が更新され、「再発行」と表示される

Amazonビジネスでは、2回目以降に開くと請求書発行日が更新されます。経理に出すファイルは、最初に保存したものに決めておくと混乱しません。

Amazonビジネスの請求書は、いつから・何件まで取れる？

Amazonビジネスのほとんどの商品には、ダウンロード可能な支払い明細書や適格請求書が付いています（公式ヘルプ「支払い明細書や適格請求書を取得する」）。取れるのは、注文が発送されてから24時間後です。

取り方 場所 件数
1件ずつ 注文履歴 → 該当する注文詳細の横の「領収書等」リンク 1件
まとめて 購買データの「注文履歴データ」ページ →「注文関連書類をダウンロードする」ボタン 一度に最大2,000
請求書払い ビジネスアカウントの設定 →「請求書情報」 1つずつ、または一度に最大2,000件をZIP

見られる範囲は役割で決まります。購買依頼者は自分の注文、グループ管理者と会計担当者はグループ内の注文、アカウント管理者はすべての注文です。1年分などの取り方は、Amazonビジネスの領収書を一括でダウンロードする方法にあります。

適格請求書か、支払い明細書か

Amazonは、出品者の登録番号の有無で、適格請求書か支払い明細書を発行します。Amazon、または登録番号をAmazonに登録した出品者の商品は適格請求書、登録番号のない出品者の注文は支払い明細書です。オンラインコード版ソフトウェアなど課税対象外の商品では、適格請求書は受け取れません。

Amazonビジネスのお客様の適格請求書は、発行日（商品の発送日）から10年間、Amazonに保管されます。適格請求書を確認するときは、「T3040001028447」がアマゾンジャパン合同会社の適格請求書発行事業者登録番号です（公式ヘルプ）。

買う前に、適格請求書が出る商品を絞り込める

ビジネスアカウント以外では、出品者が登録番号を発行しているかを、出品者に直接問い合わせて確かめる必要があります。

Amazonビジネスのビジネスアカウントに限り、検索フィルタで適格請求書の「発行対象が含まれる商品」に絞り込めます。商品詳細ページに「適格請求書の発行対象です」と表記された商品を購入すると、注文履歴から適格請求書をダウンロードできます（公式ヘルプ「インボイス（適格請求書）について」）。

会社名と請求先住所を整える

公式ヘルプには、適格請求書に受取人の会社名または団体名が含まれていない場合、その書類を適格簡易請求書として使えると書かれています。

Amazonは、Eメールによる適格請求書の修正に対応しています。依頼に応じて、適格請求書の会社名と請求先住所を修正しますが、PDF形式の適格請求書の再発行には対応していません。今後の注文に対して正しい適格請求書を発行するには、ビジネスアカウントの設定で詳細を更新する必要があります。宛名の考え方はAmazonの領収書の宛名変更にあります。

請求書払いの請求書は、「請求書情報」から取る

請求書払い（後払いで購入し、締め日から30日の支払期限で払う、Amazonビジネスの支払い方法）の請求書は、適格請求書として使えます。ダウンロードは、ビジネスアカウントの設定ページの「請求書情報」からです。

Amazonビジネスの公式ページ「Amazonでは請求書払いが利用できますか？」には、請求書は締め日から2営業日以内に、PDF形式で、事前に設定したメールアドレス宛に送付される、とあります。「請求書情報」の画面からは、過去10年分の請求書をダウンロードできるとも書かれています。

請求書は、月でまとめて1枚、または注文ごとに発行できます。締め日は5日、10日、15日、20日、25日、末日から選べます。領収書の代わりは銀行振込控です。

請求書払いは招待制で、審査があります（Amazonビジネスの公式サイト）。仕組みと申込みは、Amazonビジネスの請求書払いのやり方にまとめています。

会社名の入った請求書をまとめて取りたいなら、Amazonビジネスの登録（無料）から

Amazonビジネスのビジネスアカウントなら、検索フィルタで適格請求書の「発行対象が含まれる商品」に絞り込めます（ビジネスアカウント以外では、出品者への直接の問い合わせが必要です）。請求書は発送の24時間後から注文履歴で取れ、購買データからは一度に最大2,000件をダウンロードできます。請求書払いは審査のある招待制で、請求書はPDFでメールに届きます。登録は無料（公式サイトの表記）で、個人アカウントとはアカウントの切り替えで行き来できます。月に数件だけなら、個人アカウントの手順で足ります。

アカウントの切り替えは、デスクトップブラウザでは「［貴社名］のアカウント」メニューの「アカウントの切り替え」から行います（公式ヘルプ）。共有のパソコンでは、この機能を使わないよう勧められています。

見積書・納品書・請求書払いは、請求書とは別の書類

名前が似ているため、取り違えやすい書類です。

書類 公式ヘルプの説明 詳しくは
見積書（Amazonビジネス） 参考見積書は注文確定手続き中に、見積書は注文確定後に購買データの注文履歴データでダウンロードする。参考見積書には、注文確定時に適用される割引が反映されず、配送料と手数料も載らない Amazonの見積書の出し方
納品書 個人アカウントの注文では、Amazon.co.jpが販売する商品に、一部を除き同梱されない。納品書が同梱されていないときは、「請求書を表示する」からパッケージの請求書を印刷できる Amazonの納品書の記事
請求書払い 後払いで購入し、締め日から30日の支払期限で払う、Amazonビジネスの支払い方法。請求書払いの請求書が出るのは、この支払い方法を使うとき 請求書払いのやり方

コンビニ、ATM、インターネットバンキング、電子マネーで払うと、見積書は利用できません（公式ヘルプ）。

個人アカウントのままでよい？Amazonビジネスを検討する場面

個人アカウントの手順で足りるのは、請求書が必要な注文が月に数件で、買う先が主にAmazon.co.jpか、登録番号をAmazonに登録した出品者の人です。

次のどれかに当てはまるなら、Amazonビジネスを検討する場面です。

  • 一度に何十件もの請求書が要る。今回読んだ個人アカウントの公式ヘルプには、まとめて取る方法が見つかりませんでした（個人アカウントの一括ダウンロード）。Amazonビジネスは一度に最大2,000件です
  • 出品者の登録の有無を、購入前に絞り込みたい。ビジネスアカウント以外では、出品者に直接問い合わせます
  • 会社名や請求先住所を整えた適格請求書が要る
  • 請求書払いで、請求書をPDFでメールに受け取りたい（審査あり）

登録の流れはAmazon 法人アカウントの作り方、個人アカウントとの違いはAmazonビジネスと個人アカウントの違いにあります。

まとめ

Amazonの請求書は、個人アカウントでは注文履歴から出します。インボイスが要るときは「領収書等」の「明細書／適格請求書」、パッケージの請求書は「請求書を表示する」です。どちらも公式ヘルプの手順はブラウザの印刷までで、PDFにする操作はブラウザ側の機能になります。

「請求書を表示する」の書類が適格請求書にあたるかは、公式ヘルプに書かれていません。Amazonビジネスは、発送の24時間後から注文履歴で取れ、購買データから一度に最大2,000件をダウンロードできます。

税務の個別の判断は、税理士または税務署に相談してください。

よくある質問

QAmazonの請求書は、どこから出せますか？

A個人アカウントでは注文履歴から出します。インボイス（適格請求書）が要るときは、該当の注文の「領収書等」から「明細書／適格請求書」を選び、ブラウザの印刷オプションで印刷します。販売元がAmazon.co.jpか、登録番号をAmazonに登録した出品者の注文が対象です。パッケージの請求書は、日付範囲を選んで注文を探し、「請求書を表示する」から開きます。Amazonビジネスは、発送の24時間後から注文履歴の「領収書等」で取れます（公式ヘルプ、2026年11月8日確認）。

QAmazonの請求書をPDFでダウンロードするには、どうしますか？

A個人アカウントの公式ヘルプには、ダウンロードボタンの手順が見つかりませんでした。案内されているのは、書類を開いてブラウザの印刷オプションで印刷する方法です。PDFで残すなら、印刷画面の保存先でPDFを選べるかを確かめます。これはブラウザ側の機能で、Amazonの案内ではありません。Amazonビジネスは、購買データの注文履歴データから一度に最大2,000件をダウンロードできます。

QAmazonの請求書が出ない・ダウンロードできないのは、なぜですか？

A公式ヘルプから確かめられる主な理由は4つです。まだ発送されていない（発送までは閲覧も印刷もできず、Amazonビジネスは発送の24時間後から）、アプリで操作している（アプリでは印刷できない）、「明細書／適格請求書」の条件に合わない注文（出品者が登録番号をAmazonに登録していない）、支払い方法がコンビニ払いなどで領収書が出ない、です。Amazonビジネスでは、役割による見られる範囲の違いも関わります。

QAmazonビジネスの請求書は、何件までまとめて取れますか？

A購買データの「注文履歴データ」ページで「注文関連書類をダウンロードする」ボタンを使うと、一度に最大2,000の請求書をダウンロードできます。請求書払いを使っている場合は、「請求書情報」から請求書を1つずつ、または一度に最大2,000件をZIPでダウンロードできます。見られる範囲は役割で決まり、購買依頼者は自分の注文だけです。

QAmazonの見積書は、請求書の代わりになりますか？

A別の書類です。Amazonビジネスの見積書は、注文確定手続き中にダウンロードする参考見積書と、注文確定後に購買データから取る見積書の2種類で、日本語ではどちらも「見積書」という題名になります。参考見積書には、注文確定時に適用される割引が反映されません。今回読んだ公式ヘルプは、見積書を請求書や領収書の代わりとは案内していないため、経理に出す書類の名前は、提出先に確かめてください。
