備品の減価償却、10万円と30万円の境目は？少額減価償却資産と一括償却資産を解説

結論：備品の金額で経費処理の扱いが3段階に分かれる

開業時にまとめて買ったパソコンや机、複合機などの備品は、1点あたりの金額によって経費にできるタイミングが変わります。10万円未満は買った年に全額を消耗品費として経費にでき、10万〜20万円未満は一括償却資産として3年で均等に経費化、30万円未満は青色申告者に限り少額減価償却資産の特例で全額即時償却できる場合があります。どの区分に当てはまるかを取得価額ごとに確認し、通常の減価償却（耐用年数に応じた按分）との違いも押さえておくことが、開業初年度の経理を混乱させないための最初の一歩です。

通常の減価償却とは何が違うのか

備品や機械など「固定資産」に分類されるものは、本来は購入した年に全額を経費にできず、耐用年数に応じて複数年に分けて経費化します。これを減価償却といい、パソコンなら4年、応接セットなら8年など、資産の種類ごとに国税庁が定める法定耐用年数が使われます。定額法（毎年同じ額）か定率法（初年度ほど多い額）のどちらかを選び、按分して費用計上する点が特徴です。

10万円未満・10万〜20万円未満・30万円未満の各区分は、この「複数年に分けて償却する」原則に対する例外的な特例です。金額が小さい資産まで細かく耐用年数管理をするのは事務負担が大きいため、一定額未満なら簡便な処理を認めているという位置づけになります。制度の建て付けを理解しておくと、なぜ境目が設けられているのかが分かりやすくなります。

10万円・20万円・30万円の境目を表で整理する

まず自分が買った備品の税込または税抜の取得価額を確認し、以下の表でどの区分に当てはまるかを見てください。経理方式（税込経理か税抜経理か）によって判定基準額が変わる点に注意が必要です。

取得価額 処理方法 経費にできるタイミング 主な条件
10万円未満 消耗品費として即時経費 購入した年に全額 特になし（青色・白色を問わない）
10万円以上20万円未満 一括償却資産 3年間で均等に3分の1ずつ 青色・白色を問わない
20万円以上30万円未満 少額減価償却資産の特例 購入した年に全額 青色申告者のみ・年間合計に上限あり
30万円以上 通常の減価償却 耐用年数に応じて按分 青色・白色を問わない

20万円以上30万円未満は特例を使わなければ通常の減価償却になる点、10万円以上20万円未満は一括償却資産と特例のどちらも選べる点が、実務でよく混同されるポイントです。金額基準は税制改正で見直される可能性があるため、適用する年度の情報を国税庁のタックスアンサーで確認する習慣をつけてください（2026年9月11日時点の一般的な制度理解に基づく整理です）。

あなたの場合はどの区分になるか

同じ「10万円のパソコン」でも、事業形態によって使える選択肢が変わります。以下の分岐を目安に、自分の状況を当てはめてください。

  1. 白色申告の個人事業主の場合：30万円未満の特例は使えないため、10万円未満は消耗品費、10万円以上は一括償却資産（20万円未満）か通常の減価償却（20万円以上）になります。
  2. 青色申告の個人事業主・法人（中小企業者等に該当する場合）の場合：30万円未満なら特例で即時償却できる可能性があります。ただし年間の合計取得価額に上限があるため、複数点をまとめ買いした場合は注意が必要です。
  3. 開業届をまだ出していない場合：そもそも事業所得として経費計上する前提が整っていないため、先に開業届と青色申告承認申請書の提出を検討してください。
  4. 法人成りを予定している場合：個人事業主時代に買った備品を法人に引き継ぐかどうかで扱いが変わるため、法人設立のタイミングと合わせて税理士に確認することをおすすめします。

一括償却資産を選ぶときの具体的な手順

10万円以上20万円未満の備品を一括償却資産として処理する場合の流れは次のとおりです。

  1. 取得価額が10万円以上20万円未満であることを、経理方式（税込・税抜）に沿って確認する。
  2. その事業年度に取得した対象資産の取得価額を合計し、一括償却資産の帳簿を作成する。
  3. 合計額を3で割り、その事業年度から3年間、毎年同額を「一括償却資産の必要経費算入額」として計上する。
  4. 確定申告書または法人税申告書に、一括償却資産の明細を添付する。
  5. 償却期間中は固定資産台帳や会計ソフトの固定資産管理機能で残高を管理する。

一括償却資産は個別の資産ごとではなく、その年に取得した対象資産をまとめて3年均等償却する点が通常の減価償却と異なります。途中で売却・廃棄しても残りの償却額をその時点で経費に落とせないケースがあるため、償却が終わるまでの管理が必要です。

少額減価償却資産の特例を使うときの要件と手続き

30万円未満の備品について、青色申告者が使える少額減価償却資産の特例は、以下の要件を満たす場合に検討できます。

  1. 青色申告をしている個人事業主、または租税特別措置法上の中小企業者等に該当する法人であること。
  2. 取得価額が1点あたり30万円未満であること（税込・税抜は経理方式に準じる）。
  3. その事業年度における対象資産の合計取得価額が、定められた上限額以内であること（上限額や適用期限は改正の対象になりやすいため、適用年度の国税庁公式サイトで要確認）。
  4. 確定申告書または法人税申告書に、特例の適用を受ける旨と対象資産の明細を記載した書類を添付すること。
  5. 会計処理上は「少額減価償却資産」として全額をその年の費用に計上する。

この特例はあくまで「全額を即時償却できる選択肢がある」という制度であり、必ず適用しなければならないものではありません。将来の利益予測やほかの節税策とのバランスによって、通常の減価償却を選ぶ判断もあり得るため、どちらが有利かを一律に断定することはできません。

会計ソフトでの記帳と固定資産管理

備品を購入したら、まず取得価額と区分を固定資産台帳（または会計ソフトの固定資産管理機能）に記録することが基本です。会計ソフトによっては、取得価額を入力すると耐用年数の候補や一括償却資産・少額減価償却資産の対象になるかどうかの目安を表示してくれる機能があります。ただし最終的な適用可否の判断や申告書への記載は事業者側の責任で行う必要があります。

開業初年度は備品の購入が集中しやすく、消耗品費・一括償却資産・少額減価償却資産・通常の固定資産が混在しがちです。仕訳を科目ごとに分けて記帳しておかないと、確定申告の直前に区分し直す手間が発生します。日々の記帳の段階で科目と区分を意識しておくと、申告時の作業負担を減らせます。

よくある注意点と落とし穴

備品の減価償却区分でつまずきやすいポイントを整理します。

  1. セットで使う備品（パソコン本体とディスプレイなど）を分けて購入した場合、通常一体として機能するものは合算して判定される場合があります。
  2. 税込経理か税抜経理かで判定基準額をまたぐケースがあるため、経理方式を先に決めてから金額を確認する必要があります。
  3. 一括償却資産や特例の適用を受けた資産を期の途中で売却・除却した場合の処理は個別に確認が必要です。
  4. 少額減価償却資産の特例は白色申告では使えないため、青色申告承認申請書の提出状況を確認しておく必要があります。
  5. 金額基準・上限額・適用期限は税制改正の対象になりやすいため、購入時点ではなく申告時点の最新情報を確認することが大切です。

まとめ：金額の境目を先に確認してから記帳する

備品を購入したら、まず取得価額が10万円未満・10万〜20万円未満・30万円未満・30万円以上のどこに当てはまるかを確認し、自分が青色申告者かどうかで使える選択肢を絞り込みます。一括償却資産と少額減価償却資産の特例はどちらも「早く経費にできる」制度ですが、要件と上限額が異なるため、混同しないよう表で整理しておくと安心です。金額基準は税制改正で変わり得るため、申告のたびに国税庁の公式サイトで最新情報を確認する習慣をつけてください。

よくある質問

Q個人事業主でも30万円未満の特例は使えますか。

A青色申告をしている個人事業主であれば使えます。白色申告の場合はこの特例の対象外になるため、10万円未満か10万〜20万円未満の区分で処理することになります。詳細は国税庁のタックスアンサーで確認してください。

Q10万円未満かどうかは税込・税抜どちらで判定しますか。

A事業者が採用している経理方式によります。税抜経理を選んでいれば税抜金額、税込経理を選んでいれば税込金額で10万円・20万円・30万円の判定を行います。免税事業者は原則として税込金額で判定します。

Q一括償却資産と少額減価償却資産の特例、両方使える金額の備品はどちらが得ですか。

A10万円以上20万円未満の備品はどちらも選択できますが、どちらが有利かは事業年度の利益状況や翌期以降の見通しによって変わります。一律に有利不利を断定することはできないため、顧問税理士や会計ソフトのサポートに相談することをおすすめします。

Q特例には年間の上限がありますか。

A中小企業者等の少額減価償却資産の特例には年間の合計取得価額に上限が設けられています。上限額や適用期限は税制改正で変わることがあるため、適用年度の国税庁公式サイトで必ず確認してください。

Q会計ソフトを使えば区分の判定も自動でできますか。

A多くの会計ソフトには固定資産管理機能があり、取得価額を入力すると耐用年数や償却方法の候補を表示してくれます。ただし最終的にどの区分を選ぶかは事業者側の判断になるため、制度の内容は自分でも把握しておくと安心です。
