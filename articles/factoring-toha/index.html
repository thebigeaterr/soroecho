結論：ファクタリングは「請求書を手数料を引いて期日前に売る」取引

ファクタリングは、まだ入金されていない請求書（売掛債権）を、期日前に手数料を引いて売る取引です。金融庁は、法的には債権の売買（債権譲渡）契約と説明しています。

借入ではありませんが、手数料が高いとかえって資金繰りが悪化します。見るべきは手数料率の数字ではなく「手取りと入金日」です。ファクタリングを装ったヤミ金融にも注意が必要です。

この記事では次のことが分かります。

  • ファクタリングの意味と仕組み（数字の例つき）
  • 融資との違い
  • 2社間と3社間の違い
  • 手数料の見方と審査で見られる点
  • 危ない業者の見分け方と、選ぶ前のチェックリスト

あなたが個人事業主でも法人でも、基本の考え方は同じです。ただし提出書類は異なることがあります（後述）。

ファクタリングとは何か：金融庁の定義

金融庁の注意喚起ページ（2026年10月17日確認）は、ファクタリングを次のように説明しています。

事業者が保有している売掛債権等を期日前に一定の手数料を徴収して買い取るサービス（事業者の資金調達の一手段） （出典：金融庁「ファクタリングの利用に関する注意喚起」）

売掛債権とは、商品やサービスを提供したあとで「代金をあとで受け取れる権利」のことです。請求書を出したけれど、まだ入金されていない状態の代金がこれにあたります。

イメージは次のとおりです。

  1. 取引先に仕事を納め、請求書を出す
  2. 入金は1〜2か月先など、まだ先になる
  3. その請求書の権利をファクタリング会社に売る
  4. 手数料を引いた金額を、入金日より早く受け取る

株式会社No.1（会社名であり、順位を示すものではありません）の公式ページも、ファクタリングを「未回収の売掛債権（売掛金）を売却して決済日より早く資金化する」ものと説明しています。

ファクタリングの仕組みと数字の例

仕組みを数字で見てみます。次の数字はすべて架空の例であり、実際の条件ではありません。

  • 請求額：100万円
  • 手数料（仮に）：10万円
  • 手取り：90万円

つまり、100万円の請求書を売って、期日前に90万円を受け取る形です。残りの10万円が、早く現金化するための費用になります。

この例の手数料率は、説明のために置いた数字です。実際の手数料は、会社や条件ごとに異なります。

ここで大事なのは、売った請求書の代金は、あとから取引先がファクタリング会社に支払う点です。あなたが取引先から受け取って返す形ではありません。ただし契約内容によっては、この形が崩れる場合があります（危ない業者の項で触れます）。

あなたが「月末締め翌々月払い」のような長い入金サイクルで働いているなら、まず入金の流れ自体を整理すると選択肢が見えます。詳しくは フリーランスの入金サイクルと資金繰りの整理 をご覧ください。

融資との違い

ファクタリングと融資は、お金を手にする点は似ていますが、取引の性質が異なります。公式に書かれている範囲で整理します。

比べる点 ファクタリング 融資（借入）
取引の性質 売掛債権の売買（債権譲渡）契約（金融庁） お金を借りる契約
受け取る額 債権額から手数料を引いた額 借りた元本
返済 借入の返済ではなく、債権の代金は売掛先が支払う形（QuQuMo online公式は「融資とは違い弊社が売掛金を買取する」と説明） 借りた額を返す
前提 請求書（売掛債権）があること 会社ごとの条件による

信用情報の扱いについては、本記事で取り上げた公式ページに記載がないため、ここでは触れません。利用前に、各社へ直接確認してください。

注意点が一つあります。金融庁は、実態が貸付けに近いものは貸金業に該当するおそれがあるとしています。契約書に「ファクタリング」と書かれていても、中身が貸付けなら別の扱いになるということです。

2社間と3社間ファクタリング：違いと注意点

ファクタリングには、契約に関わる人の数で「2社間」と「3社間」という呼び方があります。公的機関による定義は、今回確認した範囲では見当たりません。以下は一般的な説明です。

  • 3社間：あなた・ファクタリング会社・売掛先（取引先）の3者で行う形。債権譲渡を売掛先に伝え、承諾を得て進めます。
  • 2社間：あなたとファクタリング会社の2者だけで契約する形。

各社の公式の説明は次のとおりです。

  • ラボル公式：「『ファクタリング利用者』と『ファクタリング会社（ラボル）』の2者間だけで契約できる方式」で、原則として取引先に知られることなく利用できる。ただし「ラボルへの振込が遅れる場合には、取引先に連絡させていただくことがあります。」
  • QuQuMo online公式：「当社との直接の2社間ファクタリングなので、取引先への通知や登記は一切不要で、請求書の売掛先に知られることなく資金調達ができます」
  • 株式会社No.1の公式：3社間は「売掛先企業様の承諾が必要」、2社間は「『お客様』と『ファクタリング会社』だけで取引が完結する」

あなたの場合の分岐を整理します。

  • 取引先に知られたくない場合：2社間の説明を確認します。ただし、振込が遅れたときの連絡など、例外の条件も必ず読んでください。
  • 取引先の承諾を得られる場合：3社間も選択肢になります。

手数料や条件は、2社間と3社間で別に表記している会社もあります。

手数料の見方：手取りと入金日で考える

手数料は、率だけを見ても判断を誤りやすい項目です。次の順で確認してください。

  1. 手取りを計算する：手取り＝請求額−手数料。
  2. 名目が複数ないか見る：手数料のほかに、事務手数料などの名目があれば合算します。
  3. 手数料以外の費用を確認する：アクセルファクター公式は、振込手数料、登記費用、事務手数料などの追加費用がないか確認するよう書いています。
  4. 下限だけで判断しない：同社は「手数料の下限だけで判断すると、実際の見積もりと差が出ることがあります。」とも述べています。
  5. 入金日を見る：いつ受け取れるかも、資金繰りを左右します。

会社によって表記の仕方は違います。以下は各社の公式表記を、そのまま紹介するものです。一般的な目安ではなく、優劣の比較でもありません。

会社 その会社の表記
ラボル 「手数料は一律買取額の10%のみ！振込手数料などの他の費用も一切かかりません」
株式会社No.1 「買取手数料 0.5％～15％（２社間ファクタリング：0.5%～15％ ３社間ファクタリング：0.5％～5％）」「手数料以外の費用 なし」

（出典：各社公式サイト、2026年10月17日確認）

一律の表記もあれば、幅のある表記もあります。幅のある場合は、自分の請求書でいくらになるか、見積もりで確かめる必要があります。

金融庁は、高額な手数料や大幅な割引率で契約すると資金繰りが悪化し、多重債務に陥る危険性があると注意を促しています。

審査で見られる点

金融庁等の公的資料には、ファクタリングの審査基準の記載は見当たりません。ここでは各社の公式ページが書いている範囲だけを紹介します。個別の通過条件は、会社ごとに異なります。

  • 株式会社No.1の公式：「ファクタリングは、買取った売掛債権（売掛金）が回収できるか否かを重視します。」
  • アクセルファクター公式：「売掛金が本当に存在するか、売掛先に支払い能力があるか、入金予定日がいつか」などを確認し、そのうえで買取可能額や手数料を提示する。
  • 同社は「ただし、審査なしで調達できるわけではありません。」とも書いています。

ここで紹介した2社の説明では、請求書が実在するか、売掛先から回収できるかが見られています。あなた自身の事業だけでなく、請求書の相手方も確認の対象になる、という書き方です。

準備書類の例として、QuQuMo online公式は次を挙げています。

  • 請求書（請求金額・入金日が確定しているものに限る。入金日が過ぎたものは申込不可）
  • 入出金明細（保有する全銀行口座の直近3ヶ月分）
  • 代表者本人確認書類（運転免許証またはパスポートなど）
  • 個人事業主は、開業届または青色・白色の確定申告書一式と健康保険証

あなたが開業届を出していない場合は、書類の条件を会社に事前に確認してください。

危ない業者の見分け方

金融庁は、ファクタリングを装った貸付け（偽装ファクタリング）に注意を呼びかけています。例として挙げられているのは次の3点です。

  • 債権の買取代金が、債権額に比べて著しく低額
  • 債権の回収が売主に委託され、集金できなかったときに売主が買い戻す定めがある
  • 売主自身の資金で業者に支払う定めがある

「ノンリコース」と書いてあるかなど、形式だけでは判断されないとも説明されています。

確認と相談の方法は次のとおりです。

  1. 貸金業の登録は財務局または都道府県が担当します。無登録営業は刑事罰の対象です。「登録貸金業者情報検索サービス」で確認できます。
  2. 困ったら、金融庁 金融サービス利用者相談室、警察の相談窓口、日本貸金業協会 貸金業相談・紛争解決センター、消費者ホットラインに相談できます。連絡先と受付時間は、金融庁の同ページで確認してください。

給与ファクタリング（働いた給料を受け取る権利を売る取引）は、事業者向けのファクタリングとは別物です。消費者庁は貸金業に該当するとして利用しないよう注意しており、国民生活センターも実態は貸金業で借金と同じと説明しています。

個人事業主の視点でさらに詳しく知りたい方は、個人事業主がファクタリングを使う前の注意点 もご覧ください。

選び方のチェックリスト

申し込む前に、次の項目を確認してください。

  • 手取り（請求額−手数料）を、見積もりの数字で計算した
  • 手数料の名目が複数ある場合、合算した
  • 振込手数料・登記費用・事務手数料などの追加費用の有無を確認した
  • 手数料の下限だけでなく、自分の請求書での見積もりを取った
  • 入金までの日数を確認した
  • 2社間か3社間か、取引先への連絡の有無を確認した
  • 取引先に連絡が行く例外の条件を読んだ
  • 必要書類（個人事業主は開業届など）を用意できる
  • 貸金業の登録を検索サービスで確認した
  • 契約書に、集金できなかったとき売主が買い戻す定めがないか確認した

次の一歩

急ぎで入金日を重視するなら、即日入金の見方と各社の公式表記の比較 が参考になります。そもそもの入金サイクルを整理したい方は、入金サイクルと資金繰りの記事 へどうぞ。

まとめ

ファクタリングは、請求書（売掛債権）を手数料を引いて期日前に売る、債権の売買取引です。融資とは性質が違いますが、実態が貸付けに近いものは貸金業に該当するおそれがあります。

比べるときは手数料率の数字だけでなく、「手取り」と「入金日」、追加費用の有無を見ます。2社間か3社間か、取引先への連絡がどうなるかも確認ポイントです。

最後に、貸金業の登録を検索サービスで確認し、不安があれば公的な相談窓口を使ってください。

よくある質問

Qファクタリングは借入（融資）と同じですか？

A同じではありません。金融庁は、ファクタリングを法的には債権の売買（債権譲渡）契約と説明しています。ただし同庁は、実態が貸付けに近いものは貸金業に該当するおそれがあるとも述べています。

Qファクタリングで受け取れる金額はどう計算しますか？

A手取りは「請求額−手数料」で考えます。手数料の名目が複数ある場合や、振込手数料・登記費用・事務手数料などの追加費用がある場合は、すべて合算して見積もりを比べます。

Qファクタリングに審査はありますか？

A金融庁等の公的資料に審査基準の記載は見当たりません。アクセルファクターの公式ページは「審査なしで調達できるわけではありません」と書いています。通過条件は会社ごとに異なるため、各社に確認が必要です。

Qファクタリングを装った違法業者はどう見分けますか？

A金融庁は、買取代金が債権額に比べ著しく低額、売主が集金を委託され集金できなければ買い戻す定め、などを例に挙げています。貸金業の登録は「登録貸金業者情報検索サービス」で確認できます。
