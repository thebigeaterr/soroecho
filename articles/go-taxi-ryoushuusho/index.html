GOの領収書は支払い方法で出し方が違う：結論と、この記事で分かること

GOの公式ヘルプでは、領収書の出し方は支払い方法で分かれます。GO Payなら車内では出ず、アプリの「利用履歴・領収書発行」からPDFをメールで受け取ります。車内決済なら乗務員から受け取り、アプリからは出せません。

出張や客先訪問でタクシーを使うと、あとで経費にするために領収書が要ります。ところが「どこで出すのか」「宛名はどうなるのか」「インボイスなのか」は、乗り方と払い方で変わります。

この記事では、次の内容を順に整理します。内容は2026年10月17日時点で確認した、GOの公式ヘルプと国税庁のページに基づきます。

  • 支払い方法ごとの領収書の出し方
  • GO Payの領収書の発行手順
  • 宛名について、公式で分かること・確認できなかったこと
  • まとめて発行・再発行・メールが届かないとき
  • 金額が違って見えるとき
  • インボイス（適格請求書）の扱い
  • 経費にする前のチェックリスト

タクシー領収書の出し方：車内決済とGO Payの違い

GOの公式ヘルプ「領収書はどのように発行できますか？」では、お支払い方法によって発行方法が異なると案内されています。まず、自分がどちらで払ったかを思い出すのが入口です。

支払い方法 領収書を受け取る場所 補足
車内決済 車内で乗務員から受け取る アプリからは領収書を発行できない
GO Pay アプリから発行する 車内では発行していない。PDFがメールで届く

車内決済の場合は、公式ヘルプのとおり、車内で乗務員から受け取ります。受け取り忘れたときは、利用履歴にあるタクシー会社の電話番号へ問い合わせる、と案内されています。アプリからは発行できません。

GO Payの場合は逆で、車内で頼んでも出ません。公式ヘルプによると、GO Payの乗車では車内で領収書を発行していません。理由として、領収書の二重発行を防ぐためと、クーポン利用時や事前確定運賃の注文では車内発行の領収書に正しい金額が適用されないことがあるため、と説明されています。

GO Payの領収書を発行する手順（GO 領収書 発行）

GO Payで支払った乗車の領収書は、アプリから次の手順で発行します。公式ヘルプ「GO Pay利用時の領収書発行方法」に沿った流れです。

  1. アプリ内の【≡】メニューから【利用履歴・領収書発行】を選ぶ
  2. 領収書を発行したい利用履歴を選ぶ
  3. 画面内の[領収書を発行する]を選ぶ
  4. 表示されているメールアドレスを確認して送信する

領収書はPDF形式でメールに添付して送られます。紙での領収書発行の依頼は受け付けていない、と公式に書かれています。

注意したい条件が3つあります。

  • 宛名は空欄でも発行できる
  • 「料金の内訳を表示する」はONでもOFFでも発行できる
  • GO Payで未清算があると、領収書は発行できない（決済を完了させる必要がある）

メールアドレスは送信前の確認画面で表示されます。宛先が違っていると受け取れないので、送る前に見直してください。

領収書の宛名はどうなる？公式で分かること・確認できなかったこと

宛名について、公式ヘルプで確かめられたのは「アプリの画面で宛名は空欄でも発行できる」という点だけです。急ぎで領収書だけ先に出したいときは、空欄のまま発行できます。

一方で、次の点は公式の案内では確認できませんでした。

  • 宛名に会社名や屋号を入れられるか
  • 発行したあとに宛名を直せるか

確認できなかった点は、推測で書きません。宛名が必要な場面では、発行前にアプリの画面で入力欄があるかを見て、不明ならGOのサポートに問い合わせるのが確実な順序です。

車内決済の紙の領収書についても、宛名や但し書きをどう頼むかは、GOの公式ヘルプからは確認できませんでした。必要なら、乗車したタクシー会社に確認してください。

あなたの場合で考えると、次のようになります。

  • 個人事業主：宛名の要否は、取引の内容や経理のやり方によって変わります。判断が付かないときは、税務署や税理士に確認してください。
  • 法人・屋号あり：経理のルールで宛名が求められるなら、乗車の前に、宛名が必要かどうかを決めておくと迷いません。

まとめて発行・再発行・メールが届かないとき

経費精算では、複数回の乗車をまとめて処理したい場面が多くなります。GO Payには、まとめて発行する機能があります。

公式ヘルプによると、GO Payでの乗車が複数回あるときに、領収書をまとめて発行できます。選べる内容は次のとおりです。

  • 乗車ごとに別々のPDFにするか、1つのPDFにするかを選べる
  • 利用期間やプロフィールで絞って発行できる

活用例として、「経費精算のため先月1か月分を発行したい」「1年分の利用履歴から、事業用の支払い方法で乗車した分だけ発行したい」が挙げられています。期間とプロフィールで絞り込めるので、月ごとの処理に使えます。

再発行

GO Payで支払った乗車の場合だけ、アプリの【≡】メニュー＞【利用履歴・領収書発行】から再発行できます。GO Payでない場合は、利用したタクシー会社に問い合わせてください。

メールが届かないとき

GOからのメールの送信元は go-support@goinc.jp です。公式ヘルプでは、次の点が挙げられています。

  1. 迷惑メールフォルダに自動で振り分けられていないか
  2. 「@」など一部が全角になっていないか（全角だと届かないことがある）

公式ヘルプには、ドメイン「@goinc.jp」の受信拒否設定をしていると届かないことがあり、指定受信設定をするとメールが受信できる場合がある、とも書かれています。

領収書の金額と支払い金額が違って見えるとき

車内で受け取った紙の領収書の金額が、アプリの支払い金額と合わないことがあります。公式ヘルプによると、車内で発行された紙の領収書には、手配料やクーポン利用後の金額が反映されません。

そのため、車内で紙の領収書を受け取った場合、実際の支払い金額と異なる場合があります。領収書の郵送対応などは行っていない、とも書かれています。

経費にするときは、実際に払った金額と書類の金額が一致しているかを確認します。GO Payの領収書は、アプリの【利用履歴・領収書発行】から確認できる、と公式ヘルプにあります。

GOの領収書とインボイス：公式の整理

GOの公式ヘルプ「インボイス制度への対応について」では、2023年10月1日以降の乗車分について、原則としてインボイス（適格請求書）が発行されると案内されています。発行する主体は決済方法で異なります。

  • GO Payで決済：GOアプリから、GOの登録番号が印字された電子領収書（インボイス）を発行できる
  • 車内で決済：各タクシー会社の登録番号が印字された領収書（インボイス）が車内で出るので、降車時に受け取る

GO株式会社の登録番号は T2011501015896 と案内されています。国税庁の適格請求書発行事業者公表サイトでも確認できます。

登録事業者でないタクシーに乗った場合

乗ったタクシーが登録事業者でない場合は、配車方式と決済方法でインボイスの出方が変わります。

配車方式 決済方法 インボイス
GOアプリで配車 GO Pay アプリから電子領収書（インボイス）を発行できる
GOアプリで配車 車内決済 発行できない。車内で非インボイスの領収書を受け取る
乗り場・流しで乗車 車内決済 発行できない。車内で非インボイスの領収書を受け取る
乗り場・流しで乗車 GO Pay 原則アプリから発行。車内で非インボイスの領収書を受け取る

車両ごとの登録番号は、公式の案内では確認できませんでした。また、GOの電子領収書で消費税の内訳がどう載るかも、確認できていません。

国税庁の整理：タクシーは公共交通機関特例の対象に挙がっていない

インボイスの交付が免除される「公共交通機関特例」があります。国税庁のインボイス制度Q&A（個別編）問42は、対象を3万円未満の次の運送として挙げています。

  • 船舶による旅客の運送
  • バスによる旅客の運送（一般乗合旅客自動車運送事業）
  • 鉄道・軌道による旅客の運送

タクシーは、この一覧に挙げられていません。このため、タクシー代を経費にするときは、車内で受け取る領収書や、GOの電子領収書に登録番号が付いているかを確認します。

ここで関係するのは、課税事業者（消費税を納める事業者）です。免税事業者の人や、簡易課税・2割特例を使う人は、扱いが違う場合があります。ご自身の区分に応じて、国税庁の特設サイトの記載を確認してください。個別の判断は、税理士か税務署に相談するのが筋です。

電車の領収書は新幹線の領収書、高速代はETCの領収書の記事に整理しています。

タクシーの紙の領収書についての一般論

国税庁の特設サイトでは、請求書に限らず、所定の事項が記載された書類であれば、領収書や納品書など書類の名称を問わずインボイスになる、とされています。つまり「領収書」と書かれていても、必要な事項があればインボイスとして扱われます。

なお、適格請求書は税務署長の登録を受けた適格請求書発行事業者でなければ交付できません（国税庁タックスアンサー No.6498）。

保存についても、国税庁タックスアンサー No.2070に、取引で作成・受領した書類を保存しておく必要があること、5年間の保存でよい書類の例として請求書・見積書・納品書・送り状などが挙げられています。領収書をどの期間保存するかは、ご自身の区分に応じて確認してください。電子データの保管は領収書の保存と電子文書の対応を参照してください。

経費にする前のチェックリスト

タクシー代を帳簿に入れる前に、次を確認してください。

  1. 支払い方法はGO Payか、車内決済か
  2. GO Payなら未清算がなく、領収書を発行できているか
  3. 車内決済なら、降車時に領収書を受け取ったか
  4. 登録番号（T＋13桁の数字）が印字されているか
  5. 日付・金額・乗車区間が、スケジュールや出張の記録と合っているか
  6. クーポンや手配料で、書類の金額が実際の支払いとずれていないか
  7. PDFや紙を、保存場所を決めて残したか
  8. 自分が課税事業者か、免税事業者か、簡易課税・2割特例かを把握しているか

そもそもタクシー代が経費になるかは、経費になるもの・ならないもので整理しています。請求側の書き方は請求書の書き方とインボイス対応、屋号での登録はインボイス登録と屋号も参考になります。

次の一歩：領収書を帳簿に入れる

領収書を受け取ったら、日付・金額・用途をその月のうちに帳簿へ入れておくと、確定申告の時期に慌てません。GO Payの領収書はPDFで残るため、月ごとに絞って発行し、まとめて処理する運用もできます。

よくある質問

QGOの領収書はアプリから出せますか？

AGO Payで支払った乗車は、アプリの「利用履歴・領収書発行」から発行できます。車内決済の乗車は乗務員から受け取る形で、アプリからは発行できません（GO公式ヘルプ、2026年10月17日確認）。

QGOの領収書の宛名は空欄でも発行できますか？

AGO Payの領収書は、宛名が空欄でも発行できると公式に案内されています。宛名に会社名を入れられるか、発行後に直せるかは、公式の案内では確認できませんでした。

QGOの領収書はインボイスになりますか？

AGO Payの場合は、GOの登録番号が印字された電子領収書がアプリから発行できます。車内決済の場合は、各タクシー会社の登録番号が印字された領収書が車内で出ます。登録事業者でない車両では扱いが変わります。

QGOの領収書メールが届かないときはどうしますか？

A送信元は go-support@goinc.jp です。迷惑メールフォルダの確認と、登録したメールアドレスの「@」などが全角になっていないかの確認が、公式ヘルプで挙げられています。
