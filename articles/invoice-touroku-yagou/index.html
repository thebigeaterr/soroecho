インボイス登録と屋号の扱い｜個人事業主が公表・請求書・変更で迷わない手順

結論：屋号は登録の必須条件ではなく、公表したいときだけ申し出る

インボイス（適格請求書発行事業者）の登録に、屋号は必須ではありません。登録の主体は、屋号ではなく「あなた個人」です。

公表サイトには、個人事業主の場合、氏名と登録番号などが載ります。屋号を載せたいときは、別に「公表事項の申出」をします。

請求書に屋号だけを書く場合は、取引先が登録番号から事業者を確認できるかがポイントです。屋号を公表しておくと、迷いが少なくなります。

この記事では、次の4点を順に整理します。

  • 登録申請書での屋号の扱い
  • 公表サイトに屋号を載せる方法
  • 請求書に屋号だけ書く場合の考え方
  • 屋号を変えたときの手続き

屋号の決め方や届出そのものは、別記事の屋号の決め方と届出のルールで扱っています。請求書全体の書き方は請求書の書き方とインボイス対応をご覧ください。

内容は、国税庁の公式ページ（2026年10月8日時点で確認した範囲）に基づきます。様式や運用は改定されることがあるため、申請前に最新の案内を見てください。

登録申請書に屋号を書く欄はあるのか

登録申請書は、あなたが「適格請求書発行事業者になる」と届け出る書類です。申請の中心は、氏名、納税地（住所）、課税事業者かどうか、といった本人を特定する情報です。

屋号の欄の有無や位置は、様式の版によって異なる場合があります。そのため、記入前に国税庁の最新の様式で、屋号の欄があるかを確認してください。

屋号を書く欄があっても、そこに書いたことが自動で公表されるとは限りません。「申請書に書くこと」と「公表サイトに載ること」は別の話として考えると、混乱しません。

あなたの状況に応じた考え方は、次のとおりです。

あなたの状況 考え方
屋号で仕事をしていて、開業届にも屋号を書いた 申請書は本人名義で出す。屋号を載せたい場合は、公表の申出を追加で検討する
屋号はあるが、開業届は出していない 登録は本人名義でできる。屋号を公表したいなら、同じく申出で足りるかを確認する
屋号がない 氏名のみで登録・公表される。何も追加しなくてよい
法人にしている（または予定がある） 法人は名称と所在地が公表される。この記事の個人向け手順とは別なので、法人の案内を確認する

申請の流れは、おおむね次のとおりです。

  1. 課税事業者か、免税事業者かを確認する（免税事業者の場合は、課税事業者になる手続きも関係します）
  2. 国税庁の最新の様式、またはオンラインの申請画面を開く
  3. 氏名、住所（納税地）などを入力する
  4. 屋号の記入欄があれば、必要に応じて記入する
  5. 公表したい事項があれば、申出の欄や別様式を確認する
  6. 提出後、登録番号の通知を受け取る

公表サイトに屋号を載せる方法（公表事項の申出）

適格請求書発行事業者の情報は、国税庁の公表サイトで誰でも検索できます。個人事業主の場合、公表されるのは原則として氏名と登録番号などです。

自宅住所は、原則として載りません。ここは「自宅住所を出したくない」方にとって大切な点です。

屋号や事務所の所在地は、あなたが申し出た場合に、追加で公表されます。これが「公表事項の申出」です。

申出をするかどうかは、取引先との関係で決めます。次の点を比べてください。

比べる点 屋号を公表する場合 公表しない場合
取引先の確認 屋号で検索して確認しやすい 氏名で確認することになる
請求書との一致 請求書の屋号と公表内容が一致する 請求書に氏名を併記すると分かりやすい
事業内容の見え方 屋号から事業が推測される 氏名のみで、事業内容は分からない
手間 申出が必要 不要

公表の申出は、おおむね次の順で進めます。

  1. 公表サイトで、自分の現在の公表内容を検索して確認する
  2. 国税庁の案内で、公表事項の申出の方法（書面またはオンライン）を確認する
  3. 載せたい屋号を、請求書で使う表記と同じ形で用意する
  4. 申出を提出する
  5. 反映後、公表サイトで屋号が表示されているかを確認する

請求書に屋号だけ書いて、本名を書かない場合の扱い

請求書（適格請求書）には、発行事業者の「氏名又は名称」と登録番号を書く必要があります。屋号で仕事をしている人は、ここに屋号だけを書いてよいのかが気になるところです。

考え方の軸は、取引先が登録番号から、その請求書の発行者を確認できるかどうかです。屋号のみの記載で足りるかは、公表サイトに屋号が出ているかどうかで、安心感が変わります。

実務では、次の整理が分かりやすいでしょう。

請求書の書き方 公表サイトに屋号を載せている 載せていない
屋号のみ 登録番号と屋号で突き合わせやすい 公表サイトで屋号が出ないため、確認しにくい
屋号＋氏名 突き合わせやすい 氏名で公表内容と合わせられる
氏名のみ 問題が起きにくい 問題が起きにくい

迷う場合は、「屋号＋氏名」の併記が最も混乱の少ない形です。たとえば「○○デザイン　山田太郎」のように書き、その横に登録番号（Tから始まる13桁）を添えます。

請求書の記載事項の全体像や、レイアウトの例は請求書の書き方とインボイス対応で説明しています。ここでは屋号の部分だけに絞りました。

屋号のみで発行したい場合の手順は、次のとおりです。

  1. 公表サイトで、自分の登録番号の公表内容を確認する
  2. 屋号が出ていなければ、公表事項の申出で屋号を追加する
  3. 請求書の屋号の表記を、公表内容と同じにする
  4. 登録番号を請求書の見やすい位置に入れる
  5. 取引先から問い合わせが多い場合は、氏名の併記に切り替える

取り扱いの細部は、国税庁の最新の案内で確認してください。取引先の経理方針によって、氏名の併記を求められることもあります。

屋号を変えたときの手続き

屋号を変えても、登録番号は変わりません。登録は本人（個人）に対して行われているためです。登録のやり直しは、通常必要ありません。

ただし、公表サイトに屋号を載せている場合は、表示が古い屋号のままになります。そこで、公表事項の変更を申し出ます。

屋号を公表していない場合は、公表サイトの更新は不要です。請求書の表記を新しい屋号に変えるだけで済みます。

変更の手順は、次のとおりです。

  1. 新しい屋号の使用開始日を決める
  2. 税務署への開業届の屋号を変えるかを検討する（届出の考え方は屋号の決め方と届出のルールを参照）
  3. 公表サイトで、現在の公表内容を確認する
  4. 公表事項の変更の申出を提出する
  5. 反映を確認したうえで、請求書の屋号表記を切り替える
  6. 切り替え前後の請求書は、新旧どちらの屋号か分かるよう日付を記録しておく

切り替えの時期が重なる点には注意が必要です。公表内容の反映より先に、請求書だけ新屋号にすると、取引先が公表サイトで確認できない期間が生まれます。

そのため、請求書の切り替えは、公表の反映を確認してからにするのが安全です。反映までの期間は国税庁の案内で確認してください。

あなたの状況による分岐は、次のとおりです。

状況 やること
屋号を公表している 公表事項の変更を申し出る＋請求書の表記を変える
屋号を公表していない 請求書の表記を変える（必要なら公表の申出も検討）
屋号をやめて本名に戻す 公表している屋号を取り下げる手続きを確認し、請求書は氏名表記にする

屋号と帳簿の整理を同時に進めるなら

屋号を変えたり、公表を追加したりすると、請求書、帳簿、取引先への案内の表記がずれやすくなります。名称と登録番号を一か所で管理しておくと、あとで確認する手間が減ります。

インボイス対応の請求書の作成や、売上・経費の記帳は、会計ソフトでまとめて管理する方法があります。屋号や登録番号を設定して、請求書の書式に反映できるものもあります。

提供される機能は製品や契約内容で異なるため、請求書の発行や帳簿づけの機能は、各社の公式な案内で確認してください。

個人事業主向けの会計ソフトを見る

  • 屋号と氏名を、請求書に併記できるか
  • 登録番号を、請求書の書式に入れられるか

  • 料金や無料の範囲が、公式ページで確認できるか

登録前に確認する順番のまとめ

最後に、屋号まわりの作業を、順番にまとめます。

  1. 屋号を公表するか決める（取引先の確認しやすさと、事業内容の見え方で判断する）
  2. 申請書の最新の様式で、屋号の欄の有無を確認する
  3. 登録の申請を出し、登録番号を受け取る
  4. 公表サイトで、自分の公表内容を検索して確認する
  5. 屋号を載せる場合は、公表事項の申出を出す
  6. 請求書の表記を、公表内容と同じ形にそろえる
  7. 屋号を変えるときは、公表の変更申出を先に出してから請求書を切り替える

屋号の扱いで迷ったときは、「公表サイトを見た取引先が、請求書の発行者と同じ人だと分かるか」を基準にしてください。氏名の併記は、そのための簡単な方法です。

制度の細かい取り扱いは、国税庁のインボイス制度の案内ページと、公表サイトで確認できます。申請の直前に、最新の内容を見ておくことをおすすめします。

よくある質問

Q屋号がなくてもインボイスの登録はできますか？

Aできます。登録に屋号は必須ではありません。屋号がない場合は、個人の氏名で登録・公表され、請求書にも氏名を書けば足ります。

Q公表サイトに屋号を載せないと、登録は無効になりますか？

A無効にはなりません。個人事業主の場合、公表サイトに出るのは原則として氏名と登録番号などで、屋号の公表は申出をした場合に限られます。載せるかどうかは任意です。

Q請求書に屋号だけを書いて本名を書かなくても大丈夫ですか？

A登録番号とあわせて、どの事業者か特定できるかが論点になります。公表サイトで屋号も公表しておくと、取引先が確認しやすくなります。取り扱いは国税庁の最新の案内で確認してください。

Q屋号を変えたら、インボイスの登録をやり直す必要がありますか？

A登録番号は変わらないため、登録のやり直しは通常必要ありません。公表サイトに屋号を載せている場合は、公表事項の変更を申し出て表示を更新します。
