結論：期首に替え、保存してから解約する

会計ソフトの乗り換えは、新しい事業年度の初めに合わせると手間が最も少なくなります。移すものは主に「開始残高」と「各種の登録情報」です。

旧ソフトの解約は最後に行います。帳簿と決算書を手元に保存してからにしてください。

この記事は乗り換えの作業手順を扱います。ソフトの選び方は、既存記事「開業時の会計ソフトの選び方」をご覧ください。

乗り換えの全体像と手順

作業は次の順番で進めると、抜け漏れを防げます。

  1. 現在の年度の記帳を、できるところまで終わらせる
  2. 旧ソフトで帳簿・決算書・各種一覧を出力して保存する
  3. 新ソフトを契約し、事業の種類（個人・法人）を設定する
  4. 開始残高を入力する
  5. 勘定科目・取引先・固定資産を登録する
  6. 銀行口座やカードの連携を設定し直す
  7. 試しに数件入力して、残高が合うか確認する
  8. 問題がなければ旧ソフトを解約する

解約を7の確認まで待つのがポイントです。新ソフトで残高が合わなかったとき、旧ソフトに戻って確認できます。

旧ソフトと新ソフトを重ねて契約する期間の料金は、各サービスの公式ページで確認してください。

切り替えのタイミング：期首と期中の違い

「いつ替えるか」で、作業量は大きく変わります。

項目 期首で替える 期中で替える
入力が必要なもの 前期末の残高のみ 期首から切替日までの残高や取引
帳簿の連続性 年度ごとに分かれるため整理しやすい 1年分が2つのソフトに分かれる
手間 少ない 多い
年度末の集計 新ソフトだけで完結 両方の出力を合わせる必要がある

個人事業主は事業年度が1月から12月です。そのため、1月からの記帳を新ソフトで始めるのが、最も区切りがよい形です。

法人は決算日の翌日が期首です。決算書ができあがった後、新しい期の最初の取引から新ソフトで入力すると、整理しやすくなります。

期の途中で替える場合は、切替日までの記録を旧ソフトで締め、その時点の残高を新ソフトに入れます。年度末には、旧ソフトの出力と新ソフトの出力を合わせて1年分にまとめる必要があります。

何を移せば足りるか

すべてを移す必要はありません。次の5つを確認すれば、多くの場合は足ります。

移すもの 内容 注意点
開始残高 預金・売掛金・買掛金・借入金など、期首時点の残高 前年の決算書の期末残高と一致させる
勘定科目 使っている科目の名前と区分 新ソフトの標準科目との対応を決める
取引先 請求先・仕入先の名称や情報 CSV取り込みの可否はヘルプで確認
固定資産 取得日・取得価額・耐用年数・償却済額 減価償却が途切れないよう、償却累計額まで引き継ぐ
前年の決算書 貸借対照表・損益計算書など 保存用にPDFで出力する

固定資産は見落としやすい項目です。取得価額だけを入れても、すでに償却した金額がないと、今年の償却計算がずれます。

移行機能の有無は、ソフトごとに異なります。各社の公式ヘルプで、取り込みに対応している形式を確認してください。ここでは特定のソフトの機能の有無には触れません。

旧ソフトを解約する前に保存するもの

解約する前に、帳簿を保存できる状態にしておく必要があります。事業者には、帳簿や決算関係の書類を一定期間保存する義務があります。保存期間は帳簿の種類や、個人か法人かで異なります。国税庁の案内で確認してください。

保存しておく主なものは次のとおりです。

  1. 仕訳帳・総勘定元帳などの帳簿
  2. 決算書（貸借対照表・損益計算書）
  3. 固定資産台帳
  4. 請求書・領収書など、取引の証拠となる書類のデータ

保存形式は、PDFとCSVの両方があると安心です。PDFは見た目をそのまま残せます。CSVは後から別のソフトで読み込めます。

クラウド型の場合、解約後にログインできなくなる場合があります。インストール型は、ソフトが動かなくなる場合や、データの扱いが変わる場合があります。いずれも、解約後の閲覧可否を公式ヘルプで確認してください。

電子取引で受け取った請求書などのデータには、保存方法の決まりがあります。詳しくは国税庁の案内をご確認ください。

青色申告の帳簿の連続性を保つ

青色申告では、1年分の帳簿がそろっていることが前提です。乗り換えても、記録が途切れないようにします。

確認のポイントは次の3つです。

  1. 前年の期末残高と、新ソフトの開始残高が一致している
  2. 期中で替える場合、旧ソフトの最終日と新ソフトの初日がつながっている
  3. 年度末に、1年分の損益と残高が確認できる

期中で替えた場合は、旧ソフトの出力と新ソフトの出力を年度末まで保管します。申告時には、両方を合わせて1年分の数字にします。

あなたの場合の分岐は次のとおりです。

  • 開業届・青色申告承認申請書を出している個人：連続性の確認が特に重要です。期首での切り替えが無理がありません。
  • 開業届をまだ出していない人：乗り換えの前に、開業の手続きとの順序を整理してください。
  • 法人（ひとり社長）：決算書と法人税の申告に必要な数字がそろう形で、期首から替えるのが基本です。

乗り換え後の確認と、よくある行き違い

新ソフトでの入力が始まったら、次の点を確認します。

  1. 試算表の残高が、旧ソフトの最終残高と合っているか
  2. 勘定科目の対応が、これまでの処理と食い違っていないか
  3. 口座連携で、過去の明細が二重に取り込まれていないか
  4. 消費税の設定（課税事業者かどうか、計算方法）が合っているか
  5. 請求書や見積書の書式が、必要な記載事項を満たしているか

よくある行き違いは、開始残高の入力ミスと、固定資産の償却累計額の入れ忘れです。旧ソフトの決算書と並べて確認すると、早く気づけます。

個人事業主の乗り換え先として、青色申告に対応したクラウド型の会計ソフトを検討する場合は、青色申告対応のクラウド会計ソフトを見るから機能や料金の案内を確認できます。移行の可否や取り込み形式は、公式ヘルプで確かめたうえで判断してください。

従業員が数名いて、給与計算も同じソフトで行っている場合は、給与データの移行も確認が必要です。年の途中で替えると、年末調整に必要な集計が分かれやすくなります。

ネットショップを運営していて、販売データを会計ソフトに取り込んでいる場合は、販売サイトとの連携設定を作り直す必要があります。連携の対応状況は、各サービスの公式ページで確認してください。

まとめ：決める順番

迷ったときは、次の順番で決めると整理しやすくなります。

  1. 事業年度の区切りに合わせて、替える日を決める
  2. 旧ソフトで保存するものを、先に書き出す
  3. 新ソフトに移す5項目を、チェックリストにする
  4. 試し入力で残高を確認する
  5. 確認できてから、旧ソフトを解約する

急いで期中に替える必要がなければ、次の期首に合わせるのが負担の少ない方法です。保存義務のある書類は、解約後も手元に残しておいてください。

よくある質問

Q会計ソフトを乗り換えるのに一番楽な時期はいつですか？

A新しい事業年度の初め（個人事業主なら1月、法人なら決算の翌日）が最も手間が少なくなります。前年の締めが終わっていれば、期末残高を開始残高として入力するだけで始められるためです。

Q旧ソフトのデータは、解約したらすぐ消えますか？

Aサービスによって扱いが異なります。解約後にデータを見られなくなる場合があるため、解約前に帳簿や決算書をPDFやCSVで保存し、公式ヘルプで保存期間と出力方法を確認してください。

Q期の途中で乗り換えても青色申告に影響しますか？

A乗り換え自体で青色申告が取り消されることはありません。ただし1年分の帳簿として通してそろえる必要があるため、旧ソフトの分と新ソフトの分を合わせて、年間の記録が途切れない状態にしておきます。

Q取引データはすべて移さないといけませんか？

A期首で替える場合は、多くの場合、開始残高と各種マスタ（勘定科目・取引先など）を移せば足ります。過去の取引明細は旧ソフトから出力して保存しておけば、新ソフトに入れ直さなくて済むことがあります。
