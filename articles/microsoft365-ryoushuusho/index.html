Microsoft 365 の領収書の結論と、この記事で分かること

Microsoft の公式ヘルプでは、ビジネス向けの Microsoft 365 について「支払い領収書は提供されません」と明記されています。事業で使う場合の書類は、Microsoft 365 管理センターで取る請求書（PDF）です。

個人用の Microsoft アカウントで買った場合は、account.microsoft.com/billing の注文履歴から「注文の詳細」を開いて印刷します。「税の請求書」が表示される場合は、そこからも取得できます。

この記事では、次の流れで説明します。

  • 契約の種類ごとの書類の入り口
  • 管理センターで請求書PDFを取る手順
  • 個人用アカウントの注文履歴から取る手順
  • 宛名の扱いと、日本の消費税・インボイスの確認点
  • 取得後に確認するチェックリスト

出典は2026年10月17日に確認した公式ページです。画面の名称や条件は、その後変わる可能性があります。

契約の種類で入り口が違う：Microsoft 365 請求書の取得先

同じ「Microsoft 365」でも、どのアカウントで買ったかによって書類の入り口が分かれます。先に自分の契約がどちらかを確認すると、探す場所を間違えません。

契約の種類 書類の入り口 主に取れる書類
ビジネス向け（職場・学校のアカウントで契約） Microsoft 365 管理センター 請求書（PDF）
個人用の Microsoft アカウントで購入（Personal / Family など） account.microsoft.com/billing の注文履歴 注文の詳細（印刷）、表示される場合は税の請求書

あなたの場合の分岐は、次のとおりです。

  • ビジネス向けを契約している法人・会社：管理センターが入り口です。
  • 個人事業主で個人用アカウントのまま購入した：注文履歴が入り口です。
  • 個人事業主でビジネス向けを契約した：管理センターが入り口です。自分に課金管理者以上の権限があるかを確認してください。
  • 職場アカウントで Microsoft Store から買った：後述のとおり、注文履歴から管理センターへ移ります。

Apple や Google 経由で Microsoft 365 を契約した場合の書類については、公式の案内で確認できませんでした。その場合は、契約した窓口の案内をご覧ください。

ビジネス向け：Microsoft 365 管理センターで請求書をPDFで取る手順

この手順は、Microsoft ビジネス サブスクリプションにのみ適用されると公式に書かれています。実行するには、少なくとも課金管理者の権限が必要です。権限がない場合は、課金管理者以上の人に依頼してください。

  1. Microsoft 365 管理センターに、職場アカウントでサインインします。
  2. 簡易ビューの場合は、[製品] を選び、[請求書の表示] を選びます。
  3. ダッシュボード ビューの場合は、[課金] から [請求と支払い] のページを開きます。
  4. 複数の課金アカウントがある場合は、[課金アカウントの変更] で対象を切り替えます。
  5. 一覧から請求書を選ぶと、詳細がオンラインで表示されます。
  6. PDFが必要なときは、[ダウンロード] を選び、[請求書のダウンロード] を選びます。

注意点として、オンライン版の請求書とダウンロードしたPDF版は異なると公式に書かれています。保存用には、PDF版を取っておく形が考えられます。

Microsoft の別の公式ページ「Microsoft Store の税の請求書、内訳、登録番号」（職場アカウント向けの説明）には、請求書について次のように書かれています。請求書は通常、支払い方法への請求後48時間以内に利用できます。請求書には、次の内容が含まれます。

  • 請求書番号と日付
  • 注文の詳細と購入したアイテム
  • 管轄区域別の税の内訳
  • 使用された支払い方法
  • 課金プロファイル情報

サブスクリプションのアイテムは、月次で請求書が作られると案内されています。

Microsoft 365 の「領収書」は出ない：請求書とカード明細で支払いを確認する

公式ヘルプには、次の趣旨の注意書きがあります。「Microsoft 365 サービスでは、支払い領収書は提供されません。クレジットまたはデビットカード支払いの場合は、請求書とクレジットまたはデビットカード請求明細書を使用して、支払いに一致します。」

つまり、領収書という名前の書類を探しても見つからない仕組みです。支払いの証拠は、請求書とカード会社の利用明細を組み合わせて残します。

一方で、特定の管轄区域では「税受領書」が使える場合があります。使える場合は、[請求と支払い] のページで請求書IDの横にあるメニューに [税受領書のダウンロード] が表示される、と公式に書かれています。日本で表示されるかどうかは、公式の案内で確認できませんでした。ご自身の画面にこの項目があるかを見て判断してください。

書類の名前については、国税庁の説明が参考になります。インボイスは、請求書に限らず、所定の事項が記載された書類であれば、領収書や納品書など名称を問わずインボイスになるとされています（出典：国税庁 インボイス制度の特設サイト）。そのため、「領収書」の名前がないこと自体は問題ではなく、書類に必要な事項が載っているかが焦点になります。

領収書と請求書の使い分けの基本は、次の記事も参照してください。

  • 領収書・電子書類の保存の考え方
  • 請求書の書き方とインボイス対応

個人用（Personal / Family など）の注文履歴から取る手順

Microsoft アカウントで個人向けのプランを買った場合は、注文履歴から書類を取ります。複数のアカウントを持っている場合は、購入に使ったアカウントでサインインしてください。

  1. account.microsoft.com/billing で注文履歴のページにサインインします。
  2. [支払 & 請求] を選び、[注文履歴] を開きます。
  3. [絞り込み] で、目的の注文と日付範囲を選びます。
  4. 状態が「完了」または「引き換え済み」になっている請求を探します。
  5. 目的の注文から [注文の詳細] を選びます。
  6. [印刷] を選んで印刷します。ブラウザーの印刷機能でも印刷できると公式に書かれています。

状態が「進行中」の請求は、まだお支払い方法に計上されていないと公式に書かれています。この段階では、書類としてまだ使えません。

クレジットカードなどに料金が転記されると、その支払い方法の明細書に金額と説明が表示されます。注文の詳細の印刷と、カード明細を並べて保存しておくと、支払いの確認に使えます。

「税の請求書」が出る場合

注文の詳細のページから [税の請求書] を選べる場合があります。ただし、次の点に注意してください。

  • リアルタイムでは取得できません。ダウンロードできるようになるまで、通常は48時間から5日かかります。
  • 公式には「VAT 請求書は、VAT が購入に適用される国/地域でのみ表示されます」とあります。
  • 日本でこの項目が表示されるかどうかは、公式の案内で確認できませんでした。

表示されない場合は、注文の詳細の印刷とカード明細を保管する形になります。

職場アカウントで Microsoft Store から買った場合

職場アカウントで Microsoft Store から購入した場合は、注文履歴から管理センターに移ります。公式の手順では、注文履歴で [このアイテムの管理] を選ぶと、Microsoft 365 管理センターで注文が開きます。

管理センターでは、次の操作ができると案内されています。

  • 請求書と請求情報にアクセスする
  • 課金プロファイルを管理する
  • 支払い履歴を表示する

つまり、入り口は注文履歴でも、書類を取る場所は前述の管理センターです。権限が必要な点も同じなので、課金管理者以上のアカウントで操作してください。

請求書の宛名・会社名はどう扱うか

経費にする書類では、宛名が屋号や会社名になっているかが気になる場面があります。管理センターでは、課金プロファイルを管理できると公式に書かれています。

ただし、請求書の宛名や会社名を直す手順の詳細は、公式の案内で確認できませんでした。そのため、ここでは具体的な操作手順は書きません。

あなたの場合の考え方は、次のとおりです。

  • 法人：請求書の宛名が会社名になっているかを、取得したPDFで確認します。
  • 個人事業主：屋号か個人名かを、日頃の帳簿の書き方に合わせて確認します。
  • 宛名を直したい：管理センターの課金プロファイルの画面と、Microsoft のサポート窓口の案内を確認してください。

なお、経費にできるかどうかの考え方は、経費になるもの・ならないもので整理しています。

日本の消費税・インボイスの確認点

Microsoft の日本向けの適格請求書発行事業者の登録番号（T番号）は、今回参照した公式ヘルプのいずれにも載っていませんでした。そのため、「インボイスとして使える」「使えない」とは断定できません。

国税庁によると、適格請求書は、税務署長の登録を受けた適格請求書発行事業者でなければ交付できません。また、インボイス制度の下では、一定の事項を記載した帳簿と請求書等の保存が仕入税額控除の要件になります（出典：国税庁 タックスアンサー No.6498）。

そこで、まず手元の書類の実物を見て、次の2点を確認してください。

  1. 登録番号（T から始まる番号）が書かれているか
  2. 消費税額（または税率ごとの対価の額）が書かれているか

登録番号は、国税庁の適格請求書発行事業者公表サイトで公表されています。サイトのトップから、ご自身で検索して確かめてください。

登録番号や消費税額が書かれていない場合

国外の事業者から受ける電気通信利用役務の提供については、国税庁が考え方を整理しています（出典：国税庁 タックスアンサー No.6118）。内容は次のとおりです。

  • 事業者向けの提供は、国内の事業者が「特定課税仕入れ」として申告・納税する（リバースチャージ方式）。
  • 一般課税で課税売上割合が95パーセント以上の課税期間や、簡易課税制度が適用される課税期間は、当分の間、特定課税仕入れはなかったものとされる。
  • 免税事業者は、消費税の確定申告等を行う必要がないため、特定課税仕入れを行っても申告等は不要。

どれに当たるかは、ご自身の課税区分によって変わります。個別の判断は、税理士や税務署に確認してください。海外サービス全般の考え方は、海外SaaSの消費税とインボイスにまとめています。

保存期間の目安

取引に伴い作成したり受け取ったりした書類は、保存しておく必要があります。国税庁によると、請求書、見積書、納品書、送り状などは5年間の保存でよい書類の例とされています（出典：国税庁 タックスアンサー No.2070）。

Microsoft 365 請求書・領収書のチェックリスト

取得した書類を、経理に回す前に確認するための一覧です。

  • 契約の種類（ビジネス向けか、個人用アカウントか）を把握した
  • 管理センター、または注文履歴から書類を取得した
  • 管理センターの場合、PDF版をダウンロードした（オンライン版とは異なるため）
  • 請求書番号、日付、購入内容が書かれている
  • 宛名が屋号・会社名・個人名のいずれで書かれているか確認した
  • 登録番号と消費税額の有無を確認した
  • カード明細書と請求書を組み合わせて保存した
  • 保存期間（5年が目安の書類）を踏まえ、保管場所を決めた
  • 判断に迷う点は、税理士または税務署に確認する予定を決めた

同じ海外サービスでも書類の出方は異なります。他のサービスの例として、Zoom の領収書やGoogle の領収書も参考になります。

次の一歩：取得した請求書を帳簿につなげる

請求書とカード明細をそろえたら、あとは帳簿に記録する作業です。毎月届く請求書は、取得から保存、記帳までの流れを決めておくと、月末の作業が軽くなります。

よくある質問

QMicrosoft 365 の領収書はダウンロードできますか？

Aビジネス向けは、公式ヘルプに「支払い領収書は提供されません」とあります。書類は管理センターで取る請求書のPDFです。個人用アカウントで買った場合は、account.microsoft.com/billing の注文履歴から注文の詳細を印刷します。

QMicrosoft 365 管理センターで請求書を見るには、どの権限が必要ですか？

A公式ヘルプでは、少なくとも課金管理者である必要があるとされています。権限がない場合は、課金管理者以上の人に依頼してください。

QMicrosoft 365 Personal の領収書の代わりになる書類はありますか？

A注文履歴の「注文の詳細」を印刷したものが、購入内容を示す書類になります。「税の請求書」が表示される場合は、そこからも取得できます。日本で表示されるかは、公式の案内で確認できませんでした。

QMicrosoft 365 の請求書はインボイス（適格請求書）になりますか？

AMicrosoft の日本向けの登録番号は、今回参照した公式ヘルプには載っていませんでした。手元の書類に登録番号と消費税額が書かれているかを確認してください。判断に迷う場合は税理士や税務署に相談してください。
