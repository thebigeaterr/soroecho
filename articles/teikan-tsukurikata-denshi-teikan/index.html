結論：電子定款なら印紙代4万円は不要、紙の定款は必要

定款は会社設立の際に必ず作成しなければならない書類で、内容に不備があると公証役場の認証を受けられません。 紙で作成した定款には収入印紙4万円を貼る必要がありますが、電子データで作成する電子定款はこの印紙税がかからず、4万円が不要になります。 これは電子定款だけの特典ではなく、印紙税法上「紙の課税文書」に該当しないために生じる違いです。

ただし電子定款を自分で作るには、電子証明書やICカードリーダーなど一定の環境を用意する必要があり、準備の手間や費用も発生します。 定款には会社法で定められた「必須記載事項」があり、これを欠くと定款自体が無効になるため、印紙代の有無以前にまず記載内容を正しく整える必要があります。 本記事では、この必須記載事項の内容、紙と電子定款の違い、電子定款を自作する場合に必要な準備、認証までの手順を順に整理します。

会社設立を控えている場合も、まだ開業届だけを出して様子を見ている場合も、定款が必要になるタイミングと内容を先に把握しておくと後の手続きがスムーズになります。 公証役場や専門家への依頼、オンラインサービスの利用など複数の選択肢を比較する視点も併せて示します。

定款に必ず書くべきこと（会社法が定める必須記載事項）

定款には、会社法27条により必ず記載しなければならない項目があります。 これを欠くと定款そのものが無効になるため、法律上、必ず記載すべき項目として扱われます。 株式会社の場合、会社法で定められた主な必須記載事項は次のとおりです。

  1. 目的（会社が行う事業の内容）
  2. 商号（会社の名称）
  3. 本店の所在地
  4. 設立に際して出資される財産の価額またはその最低額（資本金額に関わる部分）
  5. 発起人の氏名または名称および住所

このほか、発行可能株式総数など会社法に定めのある記載事項（相対的記載事項・任意的記載事項）もありますが、これらは前述の必須記載事項とは性質が異なります。相対的記載事項は「定めなくても定款自体は有効だが、その効力を生じさせるには定款に記載する必要がある事項」、任意的記載事項は「定款に記載しなくても効力に影響しないが、明確にするために記載する事項」を指します。 必須記載事項が一つでも欠けていると、公証役場での認証を受けられません。 自分で定款を作成する場合は、まずこの5項目が漏れなく入っているかを確認することが出発点になります。

例えば「目的」の記載では、実際に行う予定のない事業まで幅広く列挙すると、後から融資や許認可の審査で説明が求められる場合があります。逆に事業内容を狭く書きすぎると、将来事業を広げる際に定款変更の手続きが必要になることもあるため、現在の事業内容と今後数年の展開予定を踏まえてバランスよく記載することが望まれます。

条文の詳細は会社法27条をe-Gov法令検索の該当ページで確認してください。

紙の定款と電子定款、何が違うのか

紙の定款と電子定款は、記載する内容自体は同じです。 違うのは「紙に印刷して押印するか」「電子データとして作成し電子署名を付けるか」という作成方式の部分です。 どちらも公証役場での認証手続きは必要ですが、費用や準備するものに差があります。

比較軸 紙の定款 電子定款
作成形式 紙に印刷し押印 PDF等の電子データに電子署名
収入印紙 4万円が必要 不要
認証手数料 資本金額に応じて必要 資本金額に応じて必要（紙と同様）
必要な機器・環境 特になし（印刷環境のみ） 電子証明書、ICカードリーダー等
保存方法 紙原本を保管 電子データとして保管
向いているケース 環境整備の手間をかけたくない場合 印紙代を節約し、環境をすでに持っている場合

認証手数料自体は紙でも電子でも大きくは変わりませんが、収入印紙4万円の有無が最も大きな差です。 一方で電子定款を自分で作るには、後述する専用の環境を整える手間とコストがかかる点も考慮が必要です。 紙の定款は押印済みの原本をそのまま保管できるため扱いやすいと感じる場面もありますが、電子定款は原本が電子データになるため、必要に応じて認証済みのデータを印刷して使う場面もあります。 どちらの方式を選ぶかは、印紙代の負担と環境整備の手間、その後の使い方を踏まえて検討することになります。

なぜ電子定款だと印紙代4万円が不要になるのか

印紙税は、印紙税法で定められた「課税文書」に対して課される税金です。 紙で作成した定款は、この課税文書に該当するため4万円の印紙を貼る必要があります。 一方、電子データとして作成した定款は紙の文書ではないため、印紙税法上の課税文書に該当せず、印紙税がかかりません。

これが、電子定款で印紙代4万円が不要になる仕組みです。 制度としては「電子定款だから安くなる特典」ではなく、「そもそも紙の文書ではないため課税対象にならない」という整理になります。 印紙税の非課税文書の考え方については、国税庁の公式情報で最新の取り扱いを確認しておくと安心です。

なお、印紙代4万円が問題になるのは、会社設立時に作成する最初の定款（原始定款）に限られます。 設立後に定款を変更する場合の書類は、印紙税法上の課税文書としての定款原本の作成には当たらないため、この4万円の話とは別に扱われます。 細かな取り扱いは解釈によって変わることがあるため、判断に迷う場合は国税庁の公式情報や税務署への確認が有効です。

なお、電子定款であっても公証役場での認証手数料は別途かかります。 認証手数料は資本金の額などに応じて金額が変わるため、具体的な金額は日本公証人連合会の公式サイトで確認してください。

自分で電子定款を作るときに必要な環境

電子定款を自分で作成する場合、紙の定款にはない準備が必要になります。 代表的なものは次のとおりです。

  1. 定款のデータを作成するソフト（文書作成ソフトとPDF変換の機能）
  2. マイナンバーカードなどに搭載された電子証明書
  3. ICカードリーダーライター（電子証明書を読み取る機器）
  4. 電子署名を行うためのソフトウェア（PDFに署名を付与する機能）
  5. 公証役場とのやり取りに使うオンライン申請の環境（法務省が提供するシステム等）

これらを個人で一から揃える場合、ICカードリーダーの購入費や、電子署名に対応したソフトの利用環境を整える手間が発生します。たとえばICカードリーダーライターの購入費は数千円程度から、電子署名対応ソフトの利用料は無料のものから有料のものまで幅があり、いずれも公式サイトで最新の価格を確認しておくと安心です。 そのため、印紙代4万円は節約できても、環境整備にかかる時間やコストとのバランスを考える必要があります。初めて電子定款を作る場合は、環境構築だけで半日から1日程度かかることもあるため、時間的な余裕を見込んでおくと安心です。 オンラインで会社設立手続きを支援するサービスの中には、電子定款の作成部分を代行し、利用者側の環境整備を簡略化できるものもあります。

会社設立に関する情報を横断的に確認したい場合は、会社設立の公式サイトを見るのも一つの方法です。 どのサービスを使うかにかかわらず、必須記載事項の内容と認証の流れは共通して理解しておく必要があります。

定款作成から認証までの流れ

定款は作成して終わりではなく、公証役場での認証を受けて初めて効力を持ちます（株式会社の場合）。 一般的な流れは次のとおりです。

  1. 必須記載事項を含めて定款の内容を作成する
  2. 紙で作る場合は印刷・押印、電子で作る場合はPDF化して電子署名を付与する
  3. 事前に公証役場へ連絡し、定款案の確認を依頼する（公証役場によって手順が異なる場合がある）
  4. 発起人（設立者）が公証役場に出向き、または代理人を通じて認証を受ける
  5. 認証済みの定款を受け取り、設立登記の際に法務局へ提出する

紙の定款は原本を公証役場・法務局・自社でそれぞれ保管する必要がありますが、電子定款は電子データとして保管します。 公証役場に出向く際は、発起人の本人確認書類や実印（必要な場合）、代理人が手続きする場合の委任状などを求められることがあります。 持参物や事前確認の要否は公証役場によって案内が異なるため、訪問前に電話やウェブサイトで確認しておくと手続きがスムーズです。 定款案の確認から認証完了までにかかる日数も公証役場や時期によって差があるため、余裕をもったスケジュールで進めることが望まれます。目安として、事前の定款案チェックに数日、実際の認証手続き自体は当日中に終わることが多いとされていますが、混雑状況によって変動するため、公証役場の公式情報で最新の状況を確認してください。

あなたの場合はどう進めるか

定款の作り方は、読者の状況によって適した進め方が変わります。 以下の分岐を参考に、自分に近いケースを確認してください。

まだ開業届を出しておらず、個人事業主のまま様子を見ている場合は、定款は不要です。 定款が必要になるのは株式会社や合同会社など法人を設立するタイミングであり、個人事業主のままであれば作成の必要はありません。

法人設立を決めていて、自分で手続きを進めたい場合は、電子証明書などの環境を整えるか、紙で作成するかを比較検討します。 印紙代4万円と、電子定款作成に必要な機器・ソフトの費用を比べて、どちらが自分にとって負担が少ないかで判断する方法があります。すでにマイナンバーカードとICカードリーダーを持っている場合は電子定款のほうが総コストを抑えやすく、これから機器を揃える場合は紙の定款のほうが手早く済むこともあります。

自宅住所を定款や登記に出したくない場合は、本店所在地の記載方法についてバーチャルオフィスの利用などを含めて検討する余地があります。 この場合も必須記載事項として本店所在地は必要であるため、どの住所を記載するかを事前に整理しておくとスムーズです。

すでに専門家（司法書士・行政書士等）への依頼を検討している場合は、必須記載事項の内容確認や電子定款の作成部分を任せられるかどうかを、依頼前に確認しておくとよいでしょう。専門家に依頼すると報酬は発生しますが、記載内容の不備による認証やり直しのリスクを減らせる点はメリットです。

まとめ

定款には会社法で定められた必須記載事項があり、これを欠くと認証を受けられません。 紙の定款には収入印紙4万円が必要ですが、電子定款は課税文書に該当しないため印紙代が不要になります。 一方で電子定款を自分で作るには、電子証明書やICカードリーダーなどの環境整備が必要です。

定款の作成自体は数日で終えられる場合もありますが、必須記載事項の確認や環境整備には想定より時間がかかることもあります。 会社設立全体のスケジュールを立てる際は、定款作成・認証・登記申請までの流れを逆算しておくと安心です。 自分の状況（開業届の有無、法人化のタイミング、自宅住所の扱い、専門家への依頼の要否）に応じて、紙と電子のどちらで進めるか、自作するか代行を利用するかを検討してください。

制度の詳細や手数料は変更される場合があるため、実際の手続き前には公証役場や法務局など公式情報で最新の内容を確認することをおすすめします。

よくある質問

Q電子定款にすると本当に印紙代4万円はかからないのですか？

Aはい。紙の定款は印紙税法上の課税文書に該当し収入印紙4万円が必要ですが、電子データで作成した定款は課税文書に該当しないため印紙税はかかりません。ただし公証役場での定款認証手数料は電子定款でも別途必要になります。

Q定款の絶対的記載事項を1つでも忘れるとどうなりますか？

A絶対的記載事項が欠けている定款は無効となり、公証役場での認証を受けられません。目的・商号・本店所在地・出資される財産の価額（またはその最低額）・発起人の氏名や名称および住所を漏れなく記載する必要があります。

Q電子定款を自分で作るには何が必要ですか？

Aマイナンバーカード等に搭載された電子証明書、ICカードリーダーライター、電子署名に対応したソフト、PDFを作成できる環境などが必要です。これらを揃える手間やコストと、印紙代4万円の節約分を比べて検討する必要があります。

Q合同会社を設立する場合も定款認証は必要ですか？

A合同会社（持分会社）は株式会社と異なり、公証役場での定款認証が不要とされています。ただし合同会社でも定款自体は作成する必要があり、絶対的記載事項の考え方は共通します。詳細は公式情報で最新の取り扱いを確認してください。

Q定款はどのタイミングで作成すればよいですか？

A会社の設立登記を申請する前に、発起人が定款を作成し、株式会社の場合は公証役場の認証を受けておく必要があります。開業届のみを出して個人事業主として活動する場合は、定款の作成自体が不要です。
