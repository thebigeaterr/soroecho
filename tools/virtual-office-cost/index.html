バーチャルオフィス費用シミュレータ

「使い方」「郵便物の転送頻度」「電話番号の要否」「契約期間」を選ぶと、バーチャルオフィスにかかる月額・年額の費用を「目安のレンジ」で試算できます。特定の事業者名や個別の料金は扱いません（事業者ごとに料金は異なり、改定もされるためです）。あわせて、その条件で契約前に確認しておきたいチェック項目も表示します。すでに自宅の住所を使って開業している場合は、住所の公開範囲に関する注意文も表示されます。試算結果はあくまで一般的な相場に基づく目安のため、実際の金額・条件は必ず各社の公式サイトでご確認ください。

月額の目安300円〜1,600円
年額の目安3,600円〜19,200円
計算の考え方
  1. 住所利用の基本料金（目安） = 「住所を使うだけ・郵便物の受け取りが多い」なら300円〜1,100円/月、「法人登記もする」なら1,000円〜3,300円/月
  2. 郵便物の転送頻度による加算（目安） = 月1回なら0円〜500円、週1回なら500円〜1,500円（転送なしは加算なし）
  3. 電話番号サービスが必要な場合の加算（目安） = 1,000円〜3,000円
  4. 月額の目安 = 基本料金 + 転送頻度の加算 + 電話番号の加算（それぞれのレンジを合算）
  5. 年額の目安 = 月払いなら月額の目安 × 12。年払いなら、月払い換算の合計に対して5〜15%引きを適用（下限は15%引き・上限は5%引きで算出し、実際に起こり得る幅を示す）

内訳（月額ベースの目安）

  • 住所利用の基本料金: 300円〜1,100円
  • 郵便物の転送: 0円〜500円
  • 電話番号サービス: 0円

契約前に確認したいこと

  • 郵便物の転送頻度と実費（1回あたりの実費・追加送料の有無）
  • 来客対応・打ち合わせスペースの要否と追加料金
  • 解約条件（違約金の有無・解約通知の期限）
  • 入会金・保証金・更新料など、月額以外の追加料金

表示している金額はすべて一般的な相場を参考にした「目安のレンジ」であり、特定の事業者の料金ではありません。実際の金額・条件は変更されることがあるため、契約前に必ず各社の公式サイトで確認してください。
